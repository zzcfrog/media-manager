# 映屿 · luminisle

**AI 驱动的素材管理助手 — 让你专注于创作，而不是整理素材。**

[UI 规范](docs/UI-SPEC.md) · [文档目录](docs/README.md) · [品牌与图标维护](docs/BRANDING.md) · [升级与数据迁移](docs/UPGRADE-AND-DATA.md)

你在剪辑时是不是也遇到过这些问题？

- 几百条素材散落在各个文件夹，想找一个镜头却无从下手
- 在 Lightroom 里给每段素材手动标注运镜、内容、人物、对话……工作量巨大
- 拍了一整天，真正开始剪辑前要花大量时间整理和筛选

映屿 · luminisle 用 AI 辅助整理素材。导入后可按需分析图片、视频和音频，结果保存在本地资料库；需要与其他编辑软件交换时，再导出 XMP 侧车文件。

界面采用 macOS 桌面风格，包含系统外观跟随、素材检查器、统一预览和剪辑工作台；原有筛选、标注、分析、创作与导出入口保留。后续界面统一参照 [UI 规范](docs/UI-SPEC.md)，历史演示截图已清理。

## 它能做什么

### AI 自动分析

一段视频丢进去，AI 会自动完成：

- **画面描述** — 这段拍了什么（人物、场景、动作）
- **语音转文字** — 谁说了什么，精确到秒
- **字幕识别** — 画面中的文字内容
- **镜头语言** — 景别（全景/中景/特写）、运镜（推拉摇移）、视角、焦段、景深
- **场景氛围** — 情绪、光线、天气、场景类型
- **色彩与主体** — 主色调、色调、影调、画面核心元素
- **风格与构图** — 拍摄风格识别（电影感、日系、纪实等）、构图分析

视频产出 13 个维度、图片产出 16 个维度的结构化标签，所有字段支持点击编辑。

### 批量分析

画廊中选中多个素材，右键一键提交批量 AI 分析。确认弹窗显示：
- 素材数量（视频/图片分别统计）
- 使用的 AI 模型
- 已有分析结果的素材处理策略（重新分析 / 跳过）

分析过程中顶部进度条实时跟踪所有任务状态。

### 无缝衔接编辑软件

分析完成后，一键将评分、标签、描述写入 **XMP 侧车文件**。这些数据可以直接被 Lightroom、Bridge、达芬奇等软件读取——你的素材在剪辑软件里就是带标签的，搜索、筛选、分类一步到位。

### 本地运行，隐私安全

资料库、工程和标注保存在本机。选择本地模型时，识别在本机执行；选择云端分析时，相应的分析输入会发送给配置的模型供应商。人脸识别和快速分类使用外置的本地模型，不会自动回退到云端。

## 功能一览

### 浏览与管理

- **多种视图** — 网格、瀑布流、等高行、列表四种布局，按 `G` 键快速切换
- **文件夹目录树** — 侧边栏 Lightroom 风格目录树，按文件夹快速筛选
- **全文搜索** — 中文分词搜索文件名、画面描述、对话内容、标签
- **多维筛选** — 类型、评分、颜色标签、喜欢、分析状态
- **排序与分组** — 按导入时间/拍摄时间/名称/分辨率/时长/大小/评分排序，支持按时间段或时长分组
- **状态持久化** — 所有筛选条件、排序、视图刷新页面后自动恢复

### 智能分析

- **多模态大模型** — 图片、视频和音乐分别配置模型，支持的本地／云端能力及「不启用」入口见设置
- **批量分析** — 选中多个素材一键排队，进度条实时跟踪
- **硬件加速压缩** — 自动检测 macOS VideoToolbox / NVIDIA NVENC / Intel QSV；实际速度取决于硬件和素材
- **图片独立配置** — 图片和视频可分别选择 AI 模型和压缩参数
- **音频分析** — 多模态统一处理或独立 ASR 引擎（本地 Whisper），支持中英文语音识别

### 收藏与评分

- **评分** — 1-5 星评分，画廊中选中多个文件后按数字键批量评分
- **喜欢** — 红心喜欢标记，按 `L` 键批量切换
- **颜色标签** — 红、黄、绿、蓝、紫五色标记，按 `6` `7` `8` `9` `0` 快速标记

### 组织与检索

- **标签** — AI 分析完成后自动关联主体、颜色、场景等标签
- **智能分类** — 1～4 级标签树、近义关系、人工合并／拆分、智能图集和例图候选；导入照片可选择后台快速分类，补充建议与人工决定分开保存
- **人物图集** — 本地人脸检测、特征及可选复核，支持命名、合并、纠正和待核对素材重扫；视频提供 1／2／3 帧每秒与 1080p／原片选择
- **查找相似** — 基于 ResNet50 深度特征 + HDBSCAN 聚类，弹窗展示酷似/相似/聚类三级结果

### 专业工具

- **XMP 写入** — 评分、颜色标签、AI 标签和描述写入标准 XMP，兼容 Adobe 全家桶
- **视频示波器** — 波形图（Waveform）、RGB Parade、Vectorscope 实时渲染（~15fps）
- **音频波形** — 可视化音频波形，点击跳转到对应时间点
- **图片全屏看图** — 缩放（25%-500%）+ 拖拽平移 + 导航缩略图 + 全屏模式
- **RGB 直方图** — 三通道色彩分布

### 导入

每次导入可独立启用智能分类或人脸归组。快速分类只处理照片；人脸归组可选择仅图片、仅视频或两者。整理在后台执行，进度及暂停／继续操作集中在 Header，导入不等待识别完成。

### 主题与语言

- **国际化** — 中文 / English 双语支持
- **桌面端** — Electron 封装，独立窗口，原生文件选择器
- **后台任务恢复** — 刷新页面后自动从后端恢复分析进度

## 快速开始

### macOS 本地安装包

项目展示名称为 **映屿 · luminisle**，采用日光、岛屿与水纹图标。Apple Silicon 本机交付版本为 **1.0.24**，视频人脸识别新增独立的 1080p／原片选项，默认 1080p；沿用双列人脸核对、待核对素材全量重扫、连续出镜归组、RAW 高清预览、可调阈值及校准、智能分类和统一后台任务。安装位置为 `/Users/zack/Applications/映屿 · luminisle.app`。程序自带运行环境，资料库保存在 `~/Library/Application Support/Media Manager/library`，模型从独立外部目录加载；替换应用升级不会替换资料库或模型，版本变更前会自动建立数据库快照。

本次正式安装包保留为 `dist/Luminisle-1.0.24-arm64.dmg`，重复压缩包和临时构建、演练副本在验证后清理；迁移副本通过应用的“资料库 → 导出完整迁移副本…”按需生成。安装、备份、恢复及离线原素材的处理方式见 [升级与数据迁移](docs/UPGRADE-AND-DATA.md)，实际安装、完整性核验和队列接续见 [1.0.24 本机更新记录](docs/local-update-1.0.24-2026-11-07.json)。以下为源码开发方式。

### 环境要求

- Python 3.12+
- [ffmpeg](https://ffmpeg.org/)（视频压缩、缩略图生成、实时转码）
- [exiftool](https://exiftool.org/)（相机元数据、XMP 写入）

### 安装

```bash
git clone https://github.com/zzcfrog/media-manager.git
cd media-manager
pip install -r requirements.txt
```

### 启动

```bash
python run.py
```

浏览器自动打开 `http://127.0.0.1:6622`。

回归验证见 [测试说明](tests/README.md)，本轮数据保护、工程保存及异步状态变更见 [修复记录](docs/code-fixes-2026-10-18.md)。

也可以通过 Electron 启动桌面端：

```bash
cd electron && npm start
```

### 配置 AI 模型

首次使用前，在右上角 **设置** 中：

1. 在通用设置指定外部模型根目录，按需下载本地模型
2. 分别为图片、视频、音乐、人脸和智能分类选择模型；暂不使用的能力选择「不启用」
3. 使用云端分析时，在供应商设置配置对应 API Key；再按需调整压缩参数和音频模式

## 技术栈

| 层 | 技术 |
|---|------|
| 前端 | Vue 3 + Quasar Framework |
| 后端 | Flask + SQLite (FTS5) |
| AI | 智谱 GLM-4V (OpenAI 兼容) + faster-whisper |
| 相似检测 | ResNet50 (ONNX) + HDBSCAN |
| 桌面端 | Electron |

## 支持的格式

**视频**：MP4 · MOV · AVI · MKV · WebM · M4V · FLV · WMV · 3GP · MTS · M2TS

> 非 H.264 格式（AVI、MKV、MTS 等）播放时自动转码。

**图片**：

- **常见格式**：JPEG · PNG · WebP · BMP · TIFF
- **Apple/HEIF**：HEIC · HEIF · HIF · AVIF
- **RAW 格式**（40+ 种）：Adobe DNG · Canon CR2/CR3/CRW · Nikon NEF/NRW · Sony ARW/SRF/SR2 · Fujifilm RAF · Olympus ORF · Panasonic/Leica RAW/RW2/RWL · Hasselblad 3FR/FFF · Phase One IIQ · Pentax PEF · Sigma X3F · Samsung SRW · Mamiya/Leaf MEF/MOS · Kodak KDC/DCR · Minolta MRW · Apple ProRAW
