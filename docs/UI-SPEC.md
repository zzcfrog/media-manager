# 映屿 · luminisle UI 规范

版本：1.43 · 更新日期：2026-11-07 · 状态：当前设计基准。

适用范围：Electron 桌面应用中的素材库、我的喜欢、人物、智能分类、标签树维护、智能图集、详情、查重、工作台、设置、菜单与弹窗。后续新增页面和控件均沿用本规范。

本规范依据当前开发界面、前端代码及用户逐轮确认的设计意图整理。它定义后续交付应达到的标准，不表示全部历史页面已完成统一，也不表示开发界面已安装到生产版本。已知差异见第 15 节。

## 1. 使用顺序与快速基准

设计或开发前，先确认页面属于哪种现有模式，再复用对应组件。视觉及布局以本文为当前基准；业务流程见 [使用指南](USAGE.md) 与 [交互设计](UE_DESIGN.md)，主题实现见 [外观主题](THEMES.md)，品牌资产见 [品牌规范](BRANDING.md)。带日期的 UI 文档仅记录历史实现，不能覆盖本文。

| 项目 | 基准 |
| --- | --- |
| 整体气质 | macOS 桌面感、紧凑、安静、温润，有克制的液态玻璃层次 |
| 工作区缝隙 | **8px**，含横向、纵向及滚动条占位 |
| 筛选栏控件 | 外高 **32px**；组合控件内部按钮通常 **28px** |
| 标题栏操作 | 导入按钮与右侧工具组外高均 **38px** |
| 控件圆角 | **10px**；2px 内缩的分段按钮使用 **8px** |
| 导航圆角 | **12px**，文件夹文字区域与导航保持一致 |
| 容器圆角 | 外层 **20px**、内层 **14px** |
| 常用字号 | 正文/导航 **13px**；筛选/菜单 **12px**；辅助 **10–11px** |
| 常用图标 | 筛选与视图 **20px**；侧栏功能 **18–20px** |
| 主题 | 温润墨玉、宣纸水墨、暖木书房、月光瓷釉，各有亮/暗模式 |
| 分段动效 | 单一选中底片滑动 **230ms**；减少动态效果时取消过渡 |
| 智能图集创建 | Footer 最左侧 **「＋智能图集」可见按钮** |

尺寸均为 CSS 逻辑像素；Retina 截图的物理像素不能直接作为布局尺寸。

## 2. 视觉原则

1. **素材优先。** 把空间留给照片、视频和音频。名称放在窗口 header，数量与当前条件放在 footer，减少重复标题和统计行。
2. **结构稳定。** 主题切换改变色彩、材质、高光、纹理和阴影；位置、尺寸、字级、圆角和操作路径保持稳定。
3. **一套几何语言。** 左侧、主区域、检查器与浮层使用相同的圆角层级、间距和对齐基线。滚动条出现前后保持相同的视觉缝隙。
4. **减框线。** 优先通过留白、表面层级和选中底片组织内容。边框用于输入边界、必要分组或按钮可识别性，避免每层容器都描边。
5. **动作可辨认。** 导航表示目的地，操作表示动作。创建、保存、导入等重要动作应让人看出可以点击，不能仅依赖悬浮提示解释。
6. **主题色有语义。** 强调色承担选中、可操作与焦点；状态色承担成功、警告和错误；素材原色与用户颜色标签保持独立。

## 3. 页面骨架与空间

### 3.1 工作区结构

```text
窗口 Header：品牌 / 当前文件夹、人物或分类名称 / 后台状态 / 导入 / 全局工具
┌────────────────┬─────────────────────────────────────────────────┐
│ 左侧导航面板   │ 筛选栏：筛选条件                 排序 / 分组 / 视图 │
│                │ 可展开高级筛选                                   │
│ 一处外层滚动   │ ┌────────────────────────┬────────────────────┐ │
│ 导航与树内展开 │ │ 素材浏览区               │ 检查器             │ │
│                │ │ 一处纵向滚动             │ 独立内容滚动       │ │
│                │ └────────────────────────┴────────────────────┘ │
│ 底部设置入口   │ Footer：＋智能图集 / 数量 / 筛选摘要 / 缩放       │
└────────────────┴─────────────────────────────────────────────────┘
```

- Header 高 56px。当前内容名称在 header 内单行显示，过长时省略并提供完整名称提示。
- 左侧面板上沿与主区域筛选栏控件上沿对齐。筛选栏紧贴工作区顶部，不增加独立文件夹标题行。
- 素材区与筛选栏共用左基线；首排素材与检查器上沿对齐。
- 检查器开关位于筛选栏最右侧，和显示相关控件处于同一区域。
- 排序／分组、视图和检查器按顺序靠右排列，间隔8px；批量标签与AI操作位于排序左侧。未选中时的隐藏操作占位不得夹在视图与检查器之间，选中／取消也不挤动这些显示控件。
- Header 的导入按钮与五按钮工具组视觉等高，工具组到窗口右侧的距离为 8px。
- 左侧导航、素材区、检查器和窗口外缘的缝隙按同一个 8px 基准计算。

### 3.2 8px 的具体含义

| 相邻边界 | 可见间距 |
| --- | --- |
| 左侧导航面板 → 主内容左边缘 | 8px |
| 筛选栏底部 → 首排素材/检查器顶部 | 8px |
| 图片 → 相邻图片，横向与纵向 | 8px |
| 素材右边缘 → 检查器 | 8px，包含素材滚动条轨道 |
| 检查器 → 窗口右边缘 | 8px |
| 内容主体 → Footer | 8px |
| 文件类型组 → 高级筛选按钮 | 8px |
| 高级筛选面板内边距及字段间距 | 8px |

8px 是工作区的主间距，不要求所有细部都使用 8px。组合控件内部允许 2px 内缩/分段间隔，图标与文字允许 4–6px，表单段落可使用 16px 或 24px。已有特殊时间线坐标和编辑画布不因主题变化重排。

**滚动条也算空间。** 素材区使用稳定的 8px 纵向 gutter，该占位即素材到检查器的缝隙，禁止再叠加一份右 padding 或容器 gap。左侧滚动条放在导航面板外缘与主区域之间的缝隙中，树条目宽度和对齐不随滚动条出现变化。

等行高布局根据实际内容盒宽度重排，不能在渲染前读取旧宽度或继续扣除已移除的16px内边距。检查器开关、侧栏伸缩、窗口缩放及缓存页面重新激活后均需更新；完整行铺满可用内容宽，末尾不足一行保留自然宽度。尺寸观察器在页面停用／卸载时释放，重新激活后恢复。窄窗口筛选栏也保持8px组件间距。

### 3.3 宽度与窄窗口

| 区域 | 当前实现基准 |
| --- | --- |
| 原生窗口 | 默认 1600×900；最小 1000×600 |
| 左侧导航布局占位 | 展开 256px；收起 56px |
| 左侧可见玻璃面板 | 布局占位减左右各 8px；占位与面板本身宽度需区分 |
| 检查器 | 288px；窗口宽度不超过 1250px 时 252px |
| 标签筛选触发区 | 82px，已选数量不撑宽控件 |
| 紧凑标签下拉 | 264px；普通维护表单选择器 360px |
| 排序 / 分组字段 | 86px / 74px；主容器不超过 1040px 时 80px / 70px |

基础筛选保持可见。空间不足时沿用现有自然换行：保持文件类型与高级筛选为不可拆的一组，标签选择与子标签/匹配方式为另一组；右侧显示操作保持完整。不得为了强行单行而把主要标签规则全部收进“更多”菜单，也不得新增第二列主导航。标签维护的主区域采用内容树与编辑区两栏，具体规则见 §11.1。

在 1000×600、1280×800 和 1600×900 检查布局。主窗口不出现整页横向滚动；允许时间线、条件摘要和已明确设计为横向滚动的高级筛选区域自行滚动。

## 4. 设计变量与圆角

复用语义变量，而不是在页面中写独立配色。以下变量已经存在，不需要为单个页面新造同义变量。

| 变量 | 用途 |
| --- | --- |
| `--workspace-gap` | 工作区缝隙，8px |
| `--app-header-height` | Header，56px |
| `--radius-panel` | 主要外容器/弹窗，20px |
| `--radius-inset` | 内嵌面板/检查器，14px |
| `--radius-navigation` | 导航与文件夹文字点击区域，12px |
| `--radius-control` | 按钮、输入和组合控件外壳，10px |
| `--bg` / `--surface` | 页面底层 / 主要内容表面 |
| `--surface2` / `--surface3` | 控件、次级分组 / 悬浮与更高层次 |
| `--text` / `--text2` / `--text3` | 正文 / 次要文字与图标 / 辅助说明 |
| `--accent` / `--accent-dim` | 强调色 / 柔和强调底色 |
| `--on-accent` / `--selected-text` | 强调底片上的反差文字和图标 |
| `--border` / `--border2` | 轻分隔 / 需要可识别的控件边界 |
| `--control` / `--control-hover` | 控件底色 / 悬浮底色 |
| `--glass` / `--glass-edge` / `--glass-light` | 玻璃底色 / 边缘 / 高光 |
| `--glass-shadow` / `--panel-shadow` | 玻璃层 / 菜单弹窗阴影 |
| `--material-filter` / `--material-grain` / `--surface-sheen` | 模糊、纹理和表面光泽 |
| `--gallery-control-height` | 图库筛选控件外高，32px |

圆角按层级使用。分段控件外壳圆角 10px、内边距 2px、内部选中底片圆角 8px；不能简单把所有层级都设成同一半径。相同角色的按钮四角、按下和悬浮形状保持一致。媒体裁切、角标和紧凑列表的小圆角属于独立角色，按第 9 节使用。

## 5. 四套主题、材质与暗色

| 名称 / ID | 材质意图 | 亮色背景 / 强调色 | 暗色背景 / 强调色 |
| --- | --- | --- | --- |
| 温润墨玉 `jade` | 青绿墨玉，温润、柔和透光 | `#f1f4ed` / `#246f60` | `#102a28` / `#8bceba` |
| 宣纸水墨 `paper` | 宣纸纹理、暖白、朱砂点缀 | `#f4f0e6` / `#a24232` | `#252722` / `#e6a18a` |
| 暖木书房 `study` | 暖木与书房感，低饱和纹理 | `#f4eddf` / `#606830` | `#2a241e` / `#c3c68e` |
| 月光瓷釉 `porcelain` | 冷青瓷釉与轻柔光泽 | `#edf3f8` / `#355fa0` | `#1d2a3b` / `#a5c7f7` |

配色表为本版代码快照，完整颜色以 `frontend/css/themes.css` 为准；修改主题变量时同步更新本文表格。默认主题为温润墨玉，无有效明暗偏好时跟随系统。主题选择和明暗选择彼此独立。

- 外观浮层采用 2×2 主题卡片，每张卡片同时展示亮/暗预览；明暗模式在下方独立选择。顶部与设置页复用同一个外观选择器。
- 各主题保留自身材质特征。墨玉/瓷釉可轻透光；宣纸/暖木以较实的表面与纹理表达，不能统一盖上强玻璃滤镜。
- 玻璃用于导航、工具组、菜单与悬浮控制；媒体图像、直方图和专业编辑画布保持准确、清楚。
- 深色边框使用主题低对比变量，不出现大面积纯白描边。文字、图标、菜单箭头、占位符、禁用态与高级筛选字段一起适配明暗。
- 选中态使用强调底色和对应反差文字；宣纸主题可沿用浅强调底色与左侧强调线的现有变体。
- 音频生成波形使用主题强调色和主题底色；真实封面、照片、视频帧及素材颜色标签保持原色。
- 开启减少透明度/增强对比度时使用不透明表面，关闭干扰阅读的纹理；不支持模糊时提供实色回退。

## 6. 字体、文字与信息密度

界面使用 macOS 系统字体族：`-apple-system, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC", sans-serif`。艺术宋体可用于品牌展示与插画式空态标题，不能替代高频控件、表格或小号元数据的系统字体。

| 文字角色 | 大小 / 字重 | 规则 |
| --- | --- | --- |
| 正文、侧栏项目 | 13px / 400–500 | 行高约 1.5 |
| 当前区域标题 | 13px / 600 | 放在 Header，不重复占据图库顶部 |
| 应用字标 | 14px / 600 | 窄窗口允许 13px |
| 筛选、下拉、标签选择器 | 12px / 400–500 | 触发文字、菜单选项及操作文字统一 |
| 元数据、分组小标题 | 10–11px / 400–600 | 不承载唯一的重要操作说明 |
| 弹窗标题 | 17px / 600 | 说明文字 12px，保持自然行高 |
| Any / All 内嵌文字 | 9.2px / 600 | 仅限已确认的 20px 专用标签图标 |

过长名称单行省略，悬浮提示或详情保留完整值；同名标签通过路径区分。数字计数使用稳定宽度或等宽数字，避免更新时跳动。中英文切换检查完整性，不能仅通过无限加宽控件适应英文。

## 7. 按钮、选择与通用状态

### 7.1 按职责选择按钮

| 职责 | 表达 |
| --- | --- |
| 重要创建/导入动作 | 加号或动作图标 + 简短文字，有可见底色或轮廓 |
| 高频工具切换 | 图标按钮，具有 tooltip、可访问名称和明确选中态 |
| 互斥选择 | 同一容器内的分段切换，单个移动选中底片 |
| 导航到目的地 | 侧栏图标 + 名称，选中样式表示当前所在位置 |
| 删除等危险动作 | 明确动作文字及危险语义，必要时展示影响与确认 |

图库筛选与 footer 操作按钮保持 32px 外高；顶栏 38px、导航条目 34px 是不同角色的明确例外。视觉图标可以小于点击区域，保持紧凑桌面操作的可点性。

### 7.2 必须设计的状态

| 状态 | 表现与行为 |
| --- | --- |
| 默认 | 文字/图标对比清楚；需要辨认的按钮有稳定表面 |
| 悬浮 | 主题悬浮底色或轻高光；不改变控件尺寸 |
| 键盘焦点 | 可见焦点标记，不能只在鼠标悬浮时显示；验收实际效果 |
| 选中/启用 | 底片、填充或标记与颜色共同表达；提供 `aria-pressed` 等状态 |
| 按下 | 轻反馈，文字/图标不位移，不引起相邻控件抖动 |
| 禁用 | 可辨认、不可提交；有需要时说明禁用原因 |
| 加载/提交中 | 防止重复提交，保留当前输入与上下文 |
| 失败 | 就近说明原因与恢复入口，重试不丢输入 |

图标按钮应能通过 Tab 到达，以 Enter/Space 激活；菜单、浮层与弹窗遵循相应的键盘交互，Escape 关闭可取消的层并合理恢复焦点。装饰 SVG 使用 `aria-hidden="true"`，文字名称由外层控件提供。对话框内的输入、按钮与错误信息均沿用主题。

正文对比度按 4.5:1、必要的非文字控件边界按 3:1 作为验收目标；当前文档不构成全项目无障碍审计通过的声明。

Toast正文、说明和操作按钮均需达到4.5:1。普通提示使用当前主题的表面与正文/次级文字色，即使调用方仍传入白字也不能在亮色表面变白。成功、警告、信息提示保留原有语义底色并使用稳定深色文字；错误与深灰进行中提示保留浅色正文。说明不再通过降低透明度削弱对比；操作按钮继承提示文字色，撤销、关闭、自动消失及读屏提示行为不变。四套主题的亮暗和系统跟随模式均需实测。

### 7.3 下拉选择器的聚焦与展开

- 所有 `QSelect` 共用规则，包含设置、图库排序/分组/高级筛选、人物、标签维护及检查器中的填充、描边和无边框选择器；普通输入框、操作菜单和说明/树选择弹层继续使用各自组件规范。
- 默认外轮廓使用10px控件圆角。聚焦未展开时，上角保留圆角、下角为直角，底部2px主题色强调线完整贴齐两侧；失焦后恢复默认。错误状态使用危险色强调线。
- 向下展开时，控件下角与菜单上角均为直角，菜单与控件同宽、左右对齐、零间隙；菜单下角保留10px圆角。向上展开时完全对称，强调线位于控件顶部。选中行采用主题强调色与浅底片，不硬编码蓝色。
- 菜单按视口剩余空间选择展开方向并限制高度，长选项换行且可滚动。窗口缩放、弹窗或页面滚动时保持衔接；控件离开视口后关闭菜单。搜索、多选、清空、键盘选择、Escape关闭与焦点返回继续沿用原组件行为。
- 弹层通过选择器自身的 `aria-controls` 与 `listbox` 关联，不按全局当前焦点猜测归属；选择器卸载时释放观察器及事件监听，不改变原组件引用和公开方法。当前代码入口为 `frontend/js/native-selects.js` 与 `frontend/css/native.css`。
- 本地模型统一使用model-select：图片、视频、音乐、人脸套装、快速分类、补充与词库模型共用菜单行结构。人脸三阶段是只读卡片，没有选择菜单。名称13px、说明11px、右侧固定动作区显示下载/已安装/删除及进度；动作与role=option平级且具有专属可访问名称，支持方向键、Enter、Escape。五个设置页的所有模型选择（含云端和独立语音转写）均提供「不启用」，停用项不显示体积、下载或删除动作，不触发模型加载。图片、视频独立启停，共享本地权重不意味着共享启停状态。选择实际模型可重新启用，确认保存后生效；取消不保存，既有配置/结果不删除。详细契约见[模型选择器](components/MODEL-SELECT.md)。

## 8. 左侧导航、文件夹与标签树

- 只保留一列主侧栏。素材库、人物、智能分类和智能图集在入口下面展开子项。
- 所有展开项共用导航最外层滚动；设置等底部固定入口不随长树滚走。树内部不额外套高度受限的滚动区。
- 收起后隐藏分组文字，所有图标居于相同水平/垂直中心线；折叠与展开不切换成另一套图标风格。
- 智能分类展开区只显示树，不附带“查找标签”“隐藏空分类”等额外控制。空分类保留。
- 标签树维护仅保留一级入口，主区域内左侧常驻标签树、右侧维护内容；不在主导航重复展示维护树，也不以下拉菜单代替内容树。
- 人物子菜单沿用「全部人物 / 待命名 / 待核对 / 已隐藏」，每项具有可区分的现有功能图标。

### 文件夹行

展开箭头和右侧文件夹行是两个独立点击/焦点区域：箭头只展开/收起，文件夹行进入该目录。悬浮、焦点与高亮范围不能互相覆盖。

当前紧凑基准：箭头图形 12px、点击区宽 24px/高 28px；文件夹图标 20px；文件夹图标与名称间距 6px；每层缩进 16px。箭头与文件夹之间不再增加额外 spacer。无子目录的行保留相同箭头占位，使同级图标对齐。

展开/收起使用不同文件夹形态；箭头用中性文字色，文件夹用主题色。名称弹性伸缩、计数靠右，计数不能挤压箭头和图标。文件夹文字区域的悬浮/选中胶囊与主导航保持 12px 圆角，当前目录可使用柔和强调底色。

## 9. 图库与检查器

### 9.1 筛选栏职责与顺序

左侧负责查找内容，右侧负责如何显示。建议以如下既有顺序组织，允许按页面适用性隐藏不适用项：

1. 文件类型分段组，紧接高级筛选按钮；高级筛选只在适用媒体类型中出现。
2. 标签组合控件：标签选择、子标签范围、任一/全部匹配。
3. 喜欢、分析状态、评分、颜色等现有条件，以及搜索与清除入口。
4. 右侧排序/方向/分组整体组件、四种视图、检查器开关及已有必要操作。

按钮外不额外散放“是否含子标签”“任意/全部”等长说明。重要筛选规则保持直接可见，完整语义通过 tooltip、可访问名称和 footer 解释。

### 9.2 标签组合

- 共同背景高 32px；标签触发区、子级范围与匹配方式组成一个整体，中间只用轻分隔线区分职责。
- 标签触发区显示「标签 N」或简短选择提示；完整路径放在下拉、tooltip 与 footer，多个选项不会撑宽首行。
- 标签下拉保留父子层级，搜索支持别名/近义表达；同名叶子保留所属路径。选择筛选父节点与“含子标签”是独立语义。
- 子标签范围按钮紧邻标签下拉。已确认图形为等大的 7×7px 节点、1.2px 圆弧分叉；包含时子节点实心并有镂空勾，关闭时空心，父节点保持实心。
- 匹配按钮使用已确认的方形 **Any / All** 标签图形，按钮 28×28px、图形 20×20px。中文可访问名称为「任一 / 全部」，tooltip 解释为“符合任一所选标签 / 同时符合全部所选标签”。
- Any 前层实心、后层空心，All 两层实心；选中底片使用主题强调色，字和图使用对应反差色，不能只在未选中和选中之间微调透明度。
- Footer 实时显示标签路径、任一/全部及子级范围。关闭高级面板不会隐式清除仍生效的条件；清除按钮必须与真实查询同步。
- 新建筛选不提供“排除标签”入口；旧图集条件如含排除项，沿用已有兼容提示与显式清除行为。

### 9.3 排序、分组与视图

排序字段、升降序和分组共用一个背景与基线，以一条轻分隔线组织；下拉菜单宽度服务于短字段内容，不使用占据大块画面的通用宽菜单。

网格、瀑布流、等高行、列表四个视图按钮同时可见，并在素材库、喜欢、人物图库、智能分类与图集中复用。图标使用实心面积而非细线框，20×20px 画布内边距与横纵缝均为 2px、块面圆角 1px；瀑布流图形使用两列错落块面。切换不丢失筛选或选区。

### 9.4 媒体显示

网格和瀑布流采用同一个 8px 缝隙；等高行的行间/行内也保持 8px。媒体卡片按角色保留约 7–9px 的现有裁切圆角，列表缩略图使用更小圆角，不套用面板 20px 圆角。

媒体悬浮以轻底色反馈，选中使用强调边界/底色；缩略图、视频帧和封面保留准确颜色。喜欢、标签、媒体类型、评分等角标使用固定位置和清晰层级，不遮住主要内容；同一状态在不同视图中使用同一图标语义。喜欢照片堆叠沿用数量角标与错位背板，并可展开/收起。

加载骨架、无匹配、缺缩略图、素材离线和读取失败分别处理。离线素材仍显示可用缓存与已有信息；不能用“无结果”掩盖读取失败。

### 9.5 检查器与 Footer

检查器与首排素材顶部对齐，标题区紧凑。信息按内容类型组织，空态说明如何选择素材；直方图/RGB 使用必要的专业通道色，不能强制套主题色而失去含义。切换素材时旧异步结果不能覆盖新素材。

Footer 不画额外强分隔线，左起为创建动作、数量、条件摘要，右侧为缩放/列数；长摘要局部省略或横向查看，数量与缩放保持可用。数量不再在图库顶部重复。

**「＋智能图集」必须像按钮。** 使用加号 + 简短文字、主题底色、1px 主题边框、悬浮反馈，32px 高、12px 字号，右侧间隔 8px。它位于 Footer 最左侧；不是与侧栏相同的纯导航图标。素材选择器中沿用隐藏条件。

## 11. 智能图集、分类维护与人物页面

- 智能图集是保存筛选规则的入口，素材变化后自动显示最新匹配结果；创建前展示当前规则快照，不复制原素材。

- 人物总览的命名、合并、待核对和隐藏使用清楚的用户词语；技术参数放到适当的设置/诊断位置，浏览入口不展示向量等实现术语。

- 点击「纠正」在按钮旁打开锚定的头像选择面板，同时仅一个；面板可搜索并直接点头像，不使用操作或目标人物下拉，也不撑高卡片或改变双列排布。面板宽480px、受视口限制并自动避让边缘，头像三列、列表限高滚动。建议人物排在前面并标注，选中头像显示主题底色、轮廓和对勾；选择不直接保存，仍需「确认纠正」。新建人物、暂不归组、非人脸、确认当前归属、忽略未归组项目和撤销保留；检查器与批量纠正复用相同头像选择器。组内8px，按钮32px。
- 纠正请求只包含打开时的人脸ID与版本；后台刷新不悄悄替换待提交版本。提交中禁用重复提交、关闭和切换核对类别；失败保留选择并就地提示，版本冲突不自动重试。取消／Escape／面板外点击关闭并将焦点还给纠正按钮，成功更新列表和Footer计数并保留撤销；若用户已离开，旧结果只刷新共享资料，不关闭新弹窗。组件契约见[人脸核对与纠正](components/PEOPLE-REVIEW.md)。
- 待核对工具栏提供次要按钮「全量重新扫描」，覆盖两个类别与所有分页关联的去重素材。确认弹窗沿用扫描弹窗、32px动作按钮与主题样式，突出素材数量；人工处理保留、离线且无高清预览时等待，说明合为短句。统计期间显示状态，失败可重试，未取得范围或数量为零时禁用开始；提交中防止重复和关闭。排队后关闭，所有队列控制集中在Header。
- 视频自动核对原因使用「出镜待核对」「归属待核对」，沿用预览图中的次级小字；只有画质不足才显示「画质不足」。原因与原图按钮以aria-describedby关联，当前／建议归属、纠正和撤销布局保持不变。

### 11.1 标签树维护

### 11.3 人物浏览与核对

- 全部人物、待命名、待核对、已隐藏的页面名称放在窗口Header。主区域不再设置重复标题、艺术宋体介绍或常驻独立任务状态行。
- 顶部左侧是人物姓名搜索，右侧是排序、网格/列表视图及新增人物、人脸识别操作；所有控件32px外高、12px字号、8px组间距。视图组内部28px，复用图库的20px实心图标与滑动选中底片；最小1000px桌面窗口保留两种视图入口。
- 工具栏「人脸识别」与空库「开始人脸识别／人脸识别设置」共用按钮规格：32px高、12px字号、上下6px及左右12px内边距、18px图标、6px图文间距，两个中央操作相隔8px。
- 人物搜索框默认四角10px，父面板不能裁切控件圆角；聚焦显示横线时下方两角变直，失焦恢复圆角。无浮动标签的32px搜索及排序控件，内部文字区也使用32px、上下零内边距，文字与箭头垂直居中，不能沿用框架40px的内部高度。
- 工具栏与首排卡片间隔8px，卡片左边与搜索框对齐，网格横纵缝隙及列表行间距均8px。右侧滚动条稳定占用8px，不再叠加左右24px留白。人物封面为方形，名字及数量紧凑排列；长姓名省略并保留完整提示。
- 待核对的两种类型在顶部工具栏切换；对比卡片按可用宽度排为网格，卡片间8px、内部12px。合并预览、判为不同人、忽略、纠正与确认原归属均保留。分页和总数放在Footer，总数不随当前页条数改变。
- Footer集中人物/核对数量、姓名搜索摘要及只读的本地任务状态，不再放暂停/继续/重试或「任务与范围」按钮；状态长文可省略并提供完整提示。人工命名与纠正随资料库保存的说明放在状态图标提示中。
- 人物相册继续使用公共媒体图库及四种视图；人物管理、组合筛选和所选人物操作沿用32px按钮与8px间距。布局调整不改变命名、隐藏、合并、纠正、封面、手动关联、识别范围或撤销行为。

### 11.4 通用设置

- 「设置 → 通用」依次显示语言、主题风格、外观模式、大模型目录四块。四个标题统一使用12px、600字重、18px行高与主题正文色；语言标题不使用其他设置页的次级字段标签样式。
- 主题与外观模式之间不设横线。通用页四套主题横排为一行四列；每套卡片内亮色预览在上、暗色预览在下，预览总高120px，主题名称位于其下，保留主题色选中标记。自动保存提示并入主题标题右侧，常规桌面窗口内四块完整可见。小窗口沿用设置内容区滚动，不压缩字段或遮挡底部操作；顶部快捷主题弹层保持原布局。
- 大模型目录显示完整路径（过长可通过title查看），使用标准dense filled路径框及明确的文件夹「选择」按钮。通过桌面文件夹选择器修改草稿，切换标签页保留；点「确定」后应用到本次运行，不要求重新打开应用；取消不改目录。默认只修改路径，保留现有文件、Hugging Face缓存配置与其他设置。环境变量覆盖时禁用选择并说明原因；浏览器或旧桌面桥接明确提示需在支持该功能的桌面应用中设置。
- 目录框下常驻显示「同时迁移现有模型」复选框，默认不勾选。尚未选择不同目录时置灰，并就地提示「先选择新的空目录」；更换目标或重新打开设置时重置，跨设置页保留草稿。旧版本已保存但尚未生效的目标可直接点确定应用。勾选后说明「复制并校验到空目录，保留原文件；完成后立即使用新目录」，不把安全复制误称为删除源文件的移动。旧桌面桥接不支持迁移或即时应用时应明确阻止，不能把等待重启误报为已生效。
- 无论仅切换还是同时迁移，点确定后设置弹窗保持打开并显示loading，所有表单及关闭动作禁用。固定操作区上方显示准备/复制/校验/应用阶段；复制和校验有明确百分比，准备和应用使用不定进度，不显示误导性的0%。完整副本通过SHA-256校验且源/目标未改变后，才保存并应用新路径；确认服务实际使用新路径后刷新本地模型清单并结束loading，窗口不重开。
- 切换前检查导入、时间调整等流式写操作，以及分析、创作构思、人脸/分类队列和模型下载；忙碌时不执行。最终切换阶段阻止新写入，避免检查后又开始任务。复制、校验或忙碌检查失败不改路径；应用服务失败则保留当时配置、原文件、已验证副本和日志，停止继续写入，不自动还原或反复重试，明确提示查看日志后重新打开应用。原根目录内的Hugging Face缓存路径跟随映射，独立缓存和环境变量覆盖不改动；独立配置的人脸ONNX、SigLIP2路径不自动重写；通过列表选用的受管理模型按稳定ID从新根目录解析。
- 原生「资料库」菜单不再放置修改模型根目录的入口；保留「打开模型目录」快捷操作。目录读取或保存失败应有可见提示，保存失败保留草稿与弹窗，部分设置已保存时重试不重复提交。

## 12. 详情、专业页面与状态连续性

详情、查重、创作工作台和设置继承同一主题、圆角、文字与动作规则，保持各自必要的专业布局。播放器、直方图、时间线和专业颜色标记按其内容语义显示。

RAW详情有版本匹配的高清缓存时可在原片离线时显示；无可用预览或解码失败时结束加载，使用主题色图标、简短原片提示及「重新读取」按钮，支持键盘重试，不展示破图或持续转圈。新照片人脸展示裁切与112px模型输入分离，保留实际画面细节，最长384px，不将放大插值宣称为新增细节。

从文件夹、喜欢、人物、分类、图集或搜索结果打开详情再返回，应恢复来源路由、筛选、排序、分组、视图、页码/加载范围、滚动和选区。主题切换、布局切换和检查器开关不能无故重置这些上下文。

列表读取、预览与提交分别考虑：首次加载、已有内容刷新、空结果、错误重试、权限/原片不可用、取消及导航后的迟到响应。错误重试保留用户输入；新请求生效后旧请求不能反写页面。后台分析/导入通过现有 Header 任务状态表达，不另加重复统计栏挤压素材区。

## 13. 动效与性能

互斥切换复用 `SlidingSegments`：一个底片在分段间滑动，230ms、`cubic-bezier(.22,.8,.25,1)`；首次显示、调整窗口与改变容器尺寸直接定位，避免从零点飞入。快速连续点击以最新状态为准，不能叠出多个高亮底片。

引擎、查重/相似档位等沿用 Quasar 反差文字的选中分段使用实色强调底片，保证两者成对；不得给浅强调底片套用白色或深色反差文字。主题变量直接驱动框架颜色，初始化配置不再写入固定的 primary/accent 色。

悬浮和展开可沿用约 120–200ms 的轻过渡，目录箭头约 150ms。动效不改变最终几何尺寸；图库选择不依靠弹跳缩放表达。减少动态效果时取消滑动/旋转过渡，保留明确最终状态。

玻璃和纹理优先用于少量界面层，避免每张缩略图都执行重模糊。风格调整不重新解码媒体、不触发真实 AI，也不为了主题色重新生成已有音频波形。
