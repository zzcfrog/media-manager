## 四视图图标

`GalleryViewIcon` 采用20×20px整数画布，外边距及横纵间隙均为2px，块面圆角1px；以实心块面和主题色绘制。网格为等尺寸四格，瀑布流为两列错落纵列，等高行为横向等高照片行，列表为缩略图与文字行。SVG为装饰，由按钮提供名称、tooltip及选中状态。

`GalleryViewControls` 同时显示四个按钮，`modelValue`与`update:modelValue`对应原`viewMode`，切换不会触发图库重载或清空选区。原快捷键与视图偏好继续生效。组件位于`GalleryPage`，智能分类、素材库、文件夹、我的喜欢及人物图库使用同一个实现。

## 分段切换与人物图标

“全部”媒体类型采用用户确认的扇形 C：图片和视频卡片轻微向两侧展开，前景音符没有外框；使用20px内联SVG随主题色及分段选中态变化。保留“全部”的可访问名称和悬浮提示，图片／视频／音乐仍为各自独立按钮。

子标签范围采用用户确认的精修 C：三个等大的7×7圆角节点，1.2px连接线与对称圆弧分叉。包含时两个子节点实心且有镂空对勾，关闭时两个子节点空心，父节点保持实心。对勾通过页面唯一的`taxonomy-descendant-checks` SVG mask真正镂空，直接露出按钮背景，适配亮暗主题和玻璃质感；原include_children状态、点击与键盘操作保持不变。SVG为装饰，由按钮提供可访问名称和aria-pressed。

`SlidingSegments` 指令为互斥按钮组提供单个移动选中底片，位置和宽度随当前按钮变化，230ms缓动；按钮本身透明，避免旧浅色背景或Quasar选中色挡住底片。覆盖图库视图、媒体类型、标签任意／全部、人物页视图、设置引擎、查重分档、相似素材分档和音频封面／波形。使用局部布局坐标，避免弹窗缩放进入时的定位偏差；首次显示和尺寸变化直接对齐，卸载时清理动画帧和ResizeObserver。系统开启减少动态效果时无滑动过渡。

人物子菜单全部人物／待命名／待核对／已隐藏分别使用群组、人物轮廓、查找人物、隐藏人物图标，遵循现有主题色和缩进。

## 标签组合控件

标签选择、精修C子标签范围与任意／全部匹配归于同一个32px背景，内部按钮28px；仅用一条轻分隔线区分标签范围和匹配方式。`TaxonomyTagPicker`新增可选`compact`布尔属性（默认false）：图库筛选栏使用82px触发按钮，以“标签 N”概括当前选择；完整路径继续出现在footer与悬浮说明中，逐项勾选及清空仍在层级菜单内操作。只在紧凑变体把下拉从360px收窄到264px，维护／编辑表单继续使用普通选择器。

匹配方式采用确认的B组标签轮廓及Any／All文字，替代此前的Venn图标：Any前层实心、后层空心，All两层实心；图文收在20×20画布内，按钮仍为28×28。背景图形采用45%不透明度，9.2px／600文字以1.35px主题背景色描边先绘制，避让标签线条。选中底片使用完整主题色，图文使用on-accent反差色，文字避让色同步底片；未选中保留灰色图文和透明底。中文可访问名称和tooltip使用“任一／全部”，footer与图集摘要同步为“任一符合”。选择器、分类树节点、素材角标、搜索建议、添加标签按钮和footer共用`TaxonomyTagIcon`单标签轮廓。共用既有滑动底片，点击已选模式不会重复加载；查询参数与保存图集条件保持原行为。

创建入口按后续反馈放到footer最左侧、素材数量之前，显示“＋智能图集”，使用主题底色、细边框和悬浮态，保持32px高、12px文字，右侧保留8px间距。footer去掉原20px水平内边距，使入口与上方素材区保持同一左基线；顶部不重复显示。侧栏分组、单个图集及弹窗共用文件夹＋实心四角星SVG，星形在24px画布内由7px扩大至10px；创建按钮独立使用加号，区分导航与添加动作。未筛选时仍可保存，素材选择器继续隐藏；弹窗冻结规则、校验、失败重试与保存后导航沿用原逻辑。前一轮选中态与底栏测量证据保留在`build/tag-match-selected-validation/`。

高级筛选与文件类型切换组成不可拆行的一组，两者相距8px；标签筛选位于其后。高级筛选按钮统一32px高、12px文字，图标继承文字主题色；展开或已有条件时使用主题强调色，关闭时使用主题次级文字色。面板左右外缘对齐主区域，内边距、组间和字段横纵间距均为8px，移除原来的多层水平padding与重复分隔线。字段及箭头覆盖旧深色硬编码颜色，改用主题变量。标签选择按钮、菜单标题、选项、搜索、计数和操作文字统一12px，保留264px紧凑菜单及默认360px表单菜单。

本轮48组媒体类型／主题／窗口测量通过，验证相邻顺序、8px间距、32px高度、主题颜色、新图标共享、footer首位及菜单12px字号；图库12组、智能图集11组、分类布局10组浏览器检查通过，图集和标签选择器状态回归通过。图集测试定位改为稳定的`.gallery-type-controls`，行为断言保留。证据位于`build/media-filter-polish-validation/`，开发版已刷新并打开高级筛选，真实素材截图为`application-advanced-filters.png`；正式应用未替换。

## 素材区边距

图库内容与筛选栏共用同一左侧基线，移除原素材滚动区的18px顶部、20px左右内边距及窄窗口14px覆盖规则。按后续反馈，左侧额外内边距归零，直接沿用侧栏外侧8px间隔；筛选栏底部、网格横纵间距、瀑布流列间距与卡片底部间距、等行高行内和行间距统一引用`--workspace-gap`（8px）。首行素材与检查器顶部仍然对齐；右侧用稳定滚动条槽提供8px间隔，不再额外叠加容器gap；检查器关闭时也移除右侧额外内边距。缩略图圆角、列数和排列算法保持原行为。网格视图的文件信息区继续保留在卡片内。

前一轮隔离Chromium实测：素材容器相对类型筛选左边缘的偏移由16px变为0，顶部相对检查器偏移由18px变为0，素材到检查器间距由36px减至16px。1728／1440／1000px窗口、智能分类／素材库／喜欢、四种视图与检查器开关共72种布局测量通过，记录见`build/gallery-spacing-validation/measurements.json`。当前统一间距增量再验证三种窗口、四套亮暗主题和三种图片视图，共72种组合的侧栏间隙、筛选栏底部间隙、横纵排列间距均为8px，左侧对齐且无整页横向溢出；记录为`rhythm-measurements.json`。现有图库控件12组浏览器检查通过。开发Electron已刷新，11,835条素材的无筛选五列瀑布流和检查器可见；最新真实素材截图为`build/gallery-spacing-validation/application-unified-gaps.png`。测试临时库已清理，正式应用尚未替换。

滚动条增量验证：1728／1000px窗口、亮暗模式、四种视图、检查器开关与有无垂直溢出共64种组合，素材内容区右侧至检查器（关闭时至内容主体右缘）的距离均为8px；稳定槽宽8px，滚轮可正常滚动，无整页横向溢出。现有图库控件12组检查通过。记录为`build/gallery-spacing-validation/scrollbar-measurements.json`，开发版真实素材截图为`application-scrollbar-gap.png`。

## 排序和分组

`GalleryOrderControls` 将排序字段、升降序与分组放在同一背景、同一基线的容器里，用一条轻分隔线区分左右两部分。素材种类与视图切换的外框统一10px圆角，2px内边距对应8px内部按钮圆角；移除素材种类遗留的6px内联圆角。字段保留文字，默认宽度86px与74px，较窄主区为80px与70px；展开菜单也缩小内边距。文件类型切换减少按钮留白，与标签、匹配方式、搜索、视图及排序组统一为32px。子标签范围以紧邻标签下拉的层级图标开关呈现，按下态表示已包含子标签，并提供明确悬浮提示；创建图集在footer使用带加号、主题底色和细边框的文字按钮，并保留可访问名称。

| 属性／事件 | 含义 |
| --- | --- |
| sortBy / update:sortBy | 排序字段；父级按原逻辑加载图库 |
| sortOrder / update:sortOrder | 升降序；父级按原逻辑加载图库 |
| groupBy / update:groupBy | 当前分组，仅改变本地展示 |
| sortOptions | 现有图库排序选项 |
| groupOptions | 时间或时长分组选项；为空时隐藏分组字段 |

子组件不持有图库筛选或接口状态；原图库继续负责不适用分组时的清空、分页与异步请求处理。辅助标签使用局部`galleryControlText`，不要求独立加载图库脚本时同时存在标签模块的全局函数。
