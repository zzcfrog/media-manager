## 配置与操作的职责

| 入口 | 内容 |
| --- | --- |
| 设置 → 人脸识别 | Buffalo L / Raccoon S、外部模型目录与已保存配置的文件状态、视频采样帧数、今后导入自动整理 |
| 设置 → 智能分类 | 快速分类模型目录、本地精补、AI 词库关系、时间/内存预算、自动应用策略、建议保留天数 |
| 人物 → 整理人物 | 本次所选/文件夹/全部历史范围、显式开始、任务查看和暂停/继续/重试/取消 |
| 标签维护 → 后台任务 | 任务查看与控制、独立质量验证、历史建议清理预览与确认 |

人物弹窗和标签后台页不再重复配置表单，保留跳转对应设置的入口。模型权重仍外部加载，保存设置不会扫描历史素材；自动整理仍只影响之后明确符合策略的导入。

## 状态与保存

两个新页共用弹窗草稿，切换页签后保留输入，取消不写入。读取保留各自加载、失败与重试状态；旧会话的迟到响应不能覆盖重开后的内容。

底部确认先检查数值范围等条件，再写入变化的部分。沿用既有 `/api/settings/`、`PATCH /api/people/settings` 和 `PATCH /api/taxonomy/configuration`，没有变更接口或数据库结构。多个接口不是一个原子事务：部分成功时明确报告已保存的部分，未完成草稿保留；重试只提交仍变化的部分。不自动恢复或反向修改已经保存的配置。

常规读取或保存不调用识别/分类任务端点。人物历史范围由独立的「开始整理」操作登记，全部历史范围继续要求明确确认。
