# 1.0.13 安装包瘦身

已生成并验证本地候选包，尚未替换本机 1.0.12。DMG 从 441,728,540 字节（441.7 MB）降至 300,696,567 字节（300.7 MB），减少 **31.93%**；解压应用从 1,253,244,830 字节降至 739,411,452 字节，减少约 41%。均使用十进制 MB/GB，文件大小与 Finder 的压缩显示可能采用不同单位。

模型权重此前已经外置，本轮缩减来自运行依赖：原包内 PyTorch 约 477 MB，torchvision 约 6 MB。图片相似度模型使用 ONNX Runtime 推理，原代码通过 torchvision 完成 PIL 缩放、裁切和归一化，导致整个 PyTorch 被打包。现以 Pillow/NumPy 完成同样操作，并在 PyInstaller 排除 torch/torchvision，保留 ONNX Runtime、CTranslate2/faster-whisper、原生媒体工具和 llama-server。

新预处理保持短边 256、双线性采样、224 中心裁切的 round 规则、float32 NCHW 及 ImageNet 归一化。9 类合成尺寸与原 torchvision 输入逐元素相同；6 组合成图片经现有只读 ONNX 模型生成的归一化特征字节也一致。模型、数据库和已有特征均无需更换或重算。

验证：81 项 Python 测试、13 项素材库状态测试、16 项前端回归及桌面路径测试通过。新冻结包 self-test、严格递归签名、DMG/ZIP 完整性通过；实际运行新包，导入两张合成图片并生成真实 2048 维 ONNX 特征，确认喜欢堆叠、展开、详情返回与检查器直方图正常，浏览器无非预期错误。合成资料库导出、校验、恢复后记录与特征保留，临时资料已删除。实际 ASR 转写与本地 VLM 生成未重跑，其运行依赖和工具继续保留，模块导入自检通过。

安装包：`dist/Luminisle-1.0.13-arm64.dmg`。SHA256：`5f187acfcd1f47f9e5a04b72ef9d0725bc168276d567f15c7aaf8d62ba1d2452`。仅本地 ad-hoc 签名，未做 Developer ID 公证。数据库、外部模型及生产应用未修改；人脸模型本轮仍停留在独立测试，没有接入应用。
