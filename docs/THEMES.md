# 外观主题

界面设计与后续 UI 变更统一参照 [UI 规范](UI-SPEC.md)。

四套完整主题：温润墨玉（`jade`）、宣纸水墨（`paper`）、暖木书房（`study`）、月光瓷釉（`porcelain`）。每套均有亮色、暗色，支持跟随系统。

本次只改变颜色、材质、阴影和边框绘制。现有侧栏、筛选栏、检查器、媒体尺寸、时间线、按钮尺寸、字体、圆角及间距保持不变；不改变素材颜色标签、分析状态或媒体本身的颜色。默认主题为温润墨玉。

## 使用方式

右上角调色盘按钮打开「外观」浮层；2×2 卡片分别显示各主题的亮暗微缩预览，下方独立选择明暗模式。点击即时生效并自动保存，不重新加载页面或切换路由。Escape、关闭按钮或点击浮层外部均可收起面板。原来的月亮按钮仍可快速轮换明暗模式。

「设置 → 通用」使用一行四套主题的预览，每套卡片内亮色在上、暗色在下，预览总高120px；名称和选中标记保留。只调整设置页的预览布局，快捷浮层仍为2×2，主题切换与自动保存行为不变。

设置 → 通用使用相同的主题控件。两处选择同步，切换主题保留当前明暗模式、素材选择、文件夹与工程状态。

## 持久化与实现

- `localStorage.appearanceTheme` 保存主题，旧 `localStorage.theme` 继续保存 `light` / `dark` / `auto`。首次使用保留原明暗偏好；旧 `accent` 值不再用于控制界面，也不删除它。
- 无效主题回退到温润墨玉，无效明暗模式回退到跟随系统。
- `frontend/js/appearance.js` 在首屏绘制前恢复主题，提供共用的选择组件。`frontend/css/themes.css` 使用统一颜色/材质变量覆盖现有样式；微缩预览共用真实主题变量。
- Quasar 主色、强调色和深色表面直接采用主题 CSS 变量，初始化不再写入固定品牌色；带反差文字的框架分段控件使用实色强调底片，避免浅底片与反差文字搭配失效。八种外观及相关修复见 [UI 走查与修复](UI-AUDIT-2026-10-31.md)。
- 明暗模式继续通过原有 Electron IPC 同步 `nativeTheme`，无需新后端接口、数据库字段或数据迁移。
- 减少透明度/增强对比度偏好会关闭透明与纹理；不支持 backdrop-filter 时使用不透明表面。

## 音频波形缩略图

音频波形随当前主题使用强调色，底色随主题表面色切换。素材库四种视图（含分组）、右侧检查器及工程素材栏使用同一着色方式；真正的音频封面、照片和视频帧保持原色，素材库与检查器的缺图占位不着色。

已有波形是导入时生成的蓝紫色 JPEG，通过显示层 SVG 滤镜提取波形覆盖度并使用主题色绘制，不重新生成缩略图、不解码原音频，也不修改数据库；原素材离线时仍可复用缓存。本修正已于 2026-10-22 打包进 1.0.9 并更新本机应用。

浏览器像素检查、封面/缺图回退及视图覆盖结果见 音频波形验证记录（历史 UI 附件已清理）。
