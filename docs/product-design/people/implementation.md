## 实施顺序

1. 人物、具体人脸、人工决定、核对与可撤销变更 → 验证独立数据库中的计数、重名、合并/拆分、负约束、过期变更冲突及列顺序。
2. 外部本地模型与持久任务 → 验证照片/视频取帧、同模型特征归组、取消/重启/离线、导入事务意图和前台优先。
3. 人物一级入口、图集、检查器与批量分析选项 → 验证真实浏览器的亮暗主题、命名/合并/纠错、筛选组合与详情返回。
4. 整体回归、文档与审查 → 记录实际通过项、未验证范围及生产发布状态。

## 已接入的完整路径

- 人物一级入口与内联子项、搜索、网格/列表、命名/同名、隐藏/恢复；详情来源还原、素材筛选组合及按文件去重。
- 合并预览/冲突/应用/受保护撤销；单脸/多脸/跨素材拆分、移动、暂不归组、误检与人工确认；无可用人脸的素材可人工加入/移出，不生成虚假脸或特征。
- 人物封面与核对分页。按页读取全部人脸，核对按完整总数翻页；不再固定只展示前100个素材或前200条核对。
- 手选封面独立保留缓存，在自动漏检、模型或源版本变化后不自动跳换；人工改归属/拒绝人脸或实际删除素材时失效。选封面不等于确认人脸或整组身份。
- 实际图片/RAW内嵌预览、视频有界内容自适应抽帧与观察时间点、离线采样计划及帧缓存；视频时间点进入已有播放器并安全定位。同一素材内完全相同的对齐人脸复用特征，所有观察仍来自实际帧。
- 外部配对 ONNX、本地推理和 CoreML 不可用时 CPU 回退；持久租约、续期、取消与迟到拒绝、前台优先、重启续跑；导入事务只登记轻量意图。
- 人工决定跨重扫/模型切换保留；原文件变更守卫、视频时点/位置匹配、固定归组锚点防止长相似链；JPEG裁切按内容去重，并保护当前及撤销引用。
- SQLite及相对缓存的完整迁移；本轮只演练隔离资料库，没有运行生产迁移或发布。

## 当前限制与后续验证

- 视频采用有界内容自适应采样，并结合已知帧率量化时间点，显示观察值；未实现运动轨迹或完整连续出场区间。为减少重复推理，本轮选择严格像素相同的局部特征复用，避免仅凭位置相近把镜头切换前后的不同人串起来。高速短暂出场仍可能漏检，可调每视频帧预算。
- 默认相似度阈值为偏保守的实现初值，尚未通过人物互斥大样本或整组聚类质量验收；新模型切换后的自动归属也需人工核对。小样本模型冒烟不等于正确率、全库吞吐或算子硬件覆盖率。
- 代表性全库导入/长时资源/实际移动硬盘性能、所有RAW机型和视频编码、真实资料库升级、正式打包和本机替换不在本轮验证范围。
- 跨素材批量纠错单次限定100个素材，界面明确提示，避免无界并发读取；可分批操作。撤销遇到成员或范围内后续变化会拒绝覆盖，需重新核对。
- 公开权重许可仍按设计说明单独核实；应用不下载或分发权重。本轮未新增模型或训练运行时依赖。
