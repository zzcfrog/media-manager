# 映屿 · luminisle 使用指南

界面设计与后续 UI 变更统一参照 [UI 规范](UI-SPEC.md)。

## 快速开始

### 环境要求

- Python 3.12+
- [ffmpeg](https://ffmpeg.org/)（视频压缩、缩略图生成、实时转码）
- [exiftool](https://exiftool.org/)（相机元数据、XMP 写入）

### 安装

```bash
pip install -r requirements.txt
```

### 启动

**方式一：浏览器**（开发调试）

```bash
python3 run.py
```

启动后自动打开浏览器访问 `http://127.0.0.1:6622`。

**方式二：Electron 桌面端**

```bash
cd electron && npm start
```

自动启动后端 Python 进程，窗口大小 1600×900，最小 1000×600。

## 导入媒体

点击左下角"导入"按钮打开导入弹窗，支持两种选择方式：

- **选择文件**：弹出系统文件选择器（支持多选）
- **选择目录**：选择整个文件夹，递归扫描
- 也可以直接将文件或文件夹拖拽到弹窗区域

导入流程自动执行：扫描匹配文件 → 小批次读取元数据 → 每批最多 2 个文件并发准备缩略图和图片相似度特征 → 逐个提交数据库并显示进度。已导入的重复文件会自动跳过；RAW 缩略图优先利用内嵌预览，图片相似度仍使用原有算法。导入窗口只渲染可见的结果卡片，滚动可查看完整结果。

进度包含成功、跳过和失败的文件，只有成功提交数据库的文件才计为“成功导入”。连接中断时已入库的素材保留，重新导入会跳过这些素材。性能对照和验证范围见 [导入性能记录](IMPORT-PERFORMANCE.md)；此优化已随 1.0.10 更新到本地安装版。

> 导入只是将文件信息写入数据库，不会移动或复制原始文件。

## 浏览与筛选

### 详情返回与喜欢照片堆叠

从“我的喜欢”或素材库文件夹打开详情，使用“返回”、Backspace 或浏览器后退，会回到进入前的来源，保留文件夹、筛选、排序、视图、已加载分页、选区与滚动位置。详情内切换上一张/下一张不会改变返回来源；主动点击侧栏则进入所点击的页面。当前会话的返回位置不跨刷新保存。

“我的喜欢”的筛选栏右侧、排列模式按钮旁提供照片堆叠，默认“酷似”，可选择“相似”“聚类”或关闭，档位自动保存。三档沿用查找重复的规则：余弦相似度 ≥0.96、≥0.90、HDBSCAN 同场景聚类，并遵守对应档位已有的排除关系。只对当前筛选命中的喜欢照片分组，视频、音乐和缺少有效特征的照片单独显示；不会自动补算特征、调用 AI、移动或删除原文件。

每组按当前排序选择第一张作为封面，缩略图外显示两层轮廓和照片数量。点击数量或聚焦后按 Enter/空格展开、收起，展开后每张仍可独立查看和操作。收起时组内隐藏照片的选区归到封面，避免误操作看不见的文件。普通点击、右键或删除只作用于实际选中的照片；“全选”仍明确选择当前筛选的全部原始素材。底部素材总数保持原始数量，分页按收起后的封面数量计算。

### 网格视图与列表视图

通过筛选栏右侧的视图切换按钮在两种视图间切换，也可以按 `G` 键快速切换。

- **网格视图**：缩略图卡片，底部滑块控制卡片大小（0.5x ~ 2x）
- **列表视图**：表头固定、可排序的表格形式

### 筛选栏

| 筛选项 | 说明 |
|--------|------|
| 类型切换 | 全部 / 图片 / 视频 |
| 星级筛选 | 点击 1-5 星筛选最低评分 |
| 颜色标签 | 红、黄、绿、蓝、紫五色筛选 |
| 喜欢 | 三态切换：全部 → 已喜欢 → 未喜欢（斜杠标识"排除"） |
| 分析状态 | 三态切换：全部 → 已分析 → 未分析（斜杠标识"排除"） |
| 搜索框 | 全文搜索（文件名 + 分析内容） |
| 排序 | 按导入时间/拍摄时间/名称/分辨率/时长/大小/评分排序 |
| 分组 | 按时间（日/周/月/季/年）或按时长分组显示 |

所有筛选条件、排序、视图模式、文件夹选择自动保存，刷新页面后保持。

> Footer 居中显示当前所有活跃的筛选条件标签，无筛选条件时不显示。

### 选择操作

- **单击**：选中
- **Ctrl/Cmd + 点击**：切换选中
- **Shift + 点击**：范围选中
- **拖拽框选**：在空白区域按住鼠标拖拽，自动框选
- **右键菜单**：查看详情、移除、查找相似、AI 分析、写入 XMP、调整拍摄时间和创建时间

### 右侧检查器

筛选栏最右侧的「检查器」按钮控制显示。单选素材时，小预览、文件名、评分和格式并排显示，下方按文件信息、拍摄与色彩、音频、日期、路径、备注和已有 AI 分析分组；没有记录的参数自动隐藏。「查看详情」和「在文件夹中显示」固定在底部。多选时保留批量分析入口。

图片显示**亮度直方图与 RGB 三通道直方图**，横轴为 0–255。它们根据缓存缩略图的 8 位像素计算，供快速参考，不代表 RAW/HDR 原始数据；不会为检查器额外读取或解码原片。原片离线但缓存仍在时可以查看；缓存缺失时显示不可用与重试。视频和音频继续显示各自参数，不显示图片直方图。

此检查器增强已随 1.0.11 更新到本地安装版。验证记录见 检查器验收（历史 UI 附件已清理） 和 [本地升级记录](local-update-1.0.11-2026-10-24.json)。

### 调整创建时间

选中一个或多个素材，右键选择「调整创建时间」。滑块范围为 **−24 到 +24 小时**，每格 1 小时：负数前移、正数后移，0 时不能应用。偏移以每个文件当前的系统创建时间为基准；打开弹窗后，操作对象固定为当时选中的素材。

点击「应用偏移」后，仅更新原文件的文件系统创建时间（macOS Finder 中的「创建时间」），不会重写照片或视频内容，也不会改动拍摄时间、修改时间、资料库导入时间和标注。没有自动撤销。时间写入精度为秒。

处理结果显示更新、跳过和失败数量。离线或已移除的文件跳过；无权限、文件系统不支持或读回校验失败计为失败，不会当成成功。连接中断时部分文件可能已经更新，应先检查，避免对已成功的文件重复偏移。此功能使用 ExifTool 的系统时间字段；当前验证平台为 macOS。

## 媒体详情

双击画廊中的卡片或选中后按 `Enter` 进入详情页。

### 视频详情

- **元数据栏**：视频信息（分辨率/时长/编码/帧率/码率/色彩空间/色彩曲线）、音频信息、拍摄设备、文件信息

- **图片预览**：支持缩放（鼠标滚轮/触控板张合）和拖拽平移，缩放范围 25%-500%
- **RGB 直方图**：三通道色彩分布

### 工具栏

返回按钮 | 文件名 | 星级评分 | 颜色标签 | 收藏 | XMP 写入（仅图片）

## AI 智能分析

### 开始分析

**单条分析**：在详情页右侧面板点击"AI 分析"按钮，弹出确认对话框显示当前设置摘要（压缩参数、AI 模型、预估码率），确认后开始分析。

**批量分析**：在画廊中选中一个或多个素材，右键选择"AI 分析"，弹出确认对话框显示：
- 素材总数（视频/图片分别计数）
- 视频/图片分析模型
- 已分析素材数量及处理策略（重新分析 / 跳过）
- 确认后在顶部进度条跟踪所有任务，已提交的素材自动跳过

### 分析流程

**视频分析**（默认多模态模式，3 个阶段）：

1. **视频压缩** — ffmpeg 压缩到设定分辨率/帧率，实时进度条
2. **视频编码** — 完成后显示压缩文件大小
3. **AI 综合分析** — 上传至 AI 服务 → 接收分析结果

**图片分析**（单阶段）：

- AI 图像分析 — 上传至 AI 服务 → 接收分析结果

### 分析结果

分析完成后，右侧面板显示分段列表。每段包含：

- **时间范围**：点击跳转视频到对应时间
- **视觉描述**：AI 对画面内容的描述
- **对话内容**：识别出的语音文字
- **字幕内容**：识别出的字幕
- **镜头维度**：景别、焦段、视角、运镜、透视
- **场景维度**：场景类型、情绪、光线、天气
- **主体/颜色**：识别出的主要拍摄对象和主色调

所有字段均可直接点击编辑，失焦自动保存。

### 删除分段

点击分段右上角的删除按钮，可选择三种删除方式：

- 延长前一段的结束时间
- 延长后一段的开始时间
- 直接删除

## 查找重复

在侧边栏点击"查找重复"进入，基于 ResNet50 视觉特征向量，支持三种相似模式：

- **酷似**：余弦相似度 ≥ 96%，如同张照片的 JPG 和 RAW
- **相似**：余弦相似度 ≥ 90%，如连拍照片
- **聚类**：HDBSCAN 密度聚类，同场景不同角度或时间

可点击"计算特征向量"补全缺失的 embedding。支持右键排除和恢复排除操作。

## XMP 侧车文件

图片完成 AI 分析后，可以点击工具栏中的 XMP 按钮将分析结果写入 XMP 侧车文件（`.xmp`）。写入内容包括：

- 评分、颜色标签
- AI 分析标签（主体、颜色、场景等）
- AI 描述文本

写入的 XMP 数据兼容 Adobe Lightroom / Bridge 等软件。支持在画廊中选中多张图片批量写入。

## 数据存储

所有数据存储在 `data/` 目录下：

- `media.db` — SQLite 数据库（媒体信息、分析结果、标签）
- `thumbnails/` — 生成的缩略图

可通过 `MEDIA_MANAGER_HOME` 环境变量更改数据目录。

### 人物相册（开发源码，尚未打包升级本机）

左侧「人物」提供全部人物、待命名、待核对和已隐藏，各子项配有相应图标。点头像进入人物图集，继续使用已有喜欢、内容标签和文件夹筛选；检查器中的「此素材中的人物」可修正认错、拆出新人物或手动关联背影/遮挡照。合并先预览，人工决定冲突需先处理；保存后可撤销，若成员后来发生变化会提示冲突。重名可保留两个独立人物。

首次点「整理人物」选择外部模型目录与范围。Buffalo L 目录需 `det_10g.onnx` 和 `w600k_r50.onnx`；Raccoon S 目录需 `det_10g_wo.onnx` 和 `w600k_mbf.onnx`。应用不自动下载或随包分发权重。「今后导入后自动整理」默认关闭，保存设置不会自动扫描历史文件；处理历史资料需另选所选素材、指定文件夹或明确确认全部历史照片/视频。已有完整 AI 分析不是前提。

人物任务可暂停、继续、重试或取消。导入、播放和前台分析优先；缺模型、原片离线、质量不足、未检测到脸和失败分别显示。视频目前按预算采样，展示检测到的时间点；未采样或未检出不能解释为人物没有出现。新模型切换保留姓名和人工决定，但新空间关联质量仍需核对。

完整迁移副本保留姓名、人工关联/排除和人物数据，以及资料库内的 `people-cache/`；模型继续从外部目录加载。该功能当前只在隔离测试库中验证，没有对本机生产资料库开启扫描。

## 性能调优

分析并发参数可在 `backend/config.py` 中调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `ANALYSIS_API_CONCURRENCY` | 2 | VLM API 最大并发请求数 |
| `ANALYSIS_THREAD_POOL_SIZE` | 5 | 批量分析线程池大小 |

仅在 API 供应商允许更高并发时才增加 `ANALYSIS_API_CONCURRENCY`。

### 智能分类（1.0.15）

本机现已预置「场景、主体、活动、视觉特征」四大维度，共1,107个节点、最多四级、153个同义表达。旧的两个无引用扁平标签已按用户要求移除。词库不会在启动时覆盖用户改动，也不会因此给旧素材自动打标签；完整层级见[默认标签树说明](DEFAULT-TAXONOMY.md)。

“智能分类”在左侧只展开分类树，不附加查找、隐藏空分类或内层滚动；所有展开项共用侧栏最外层滚动。“标签树维护”左侧只保留入口，进入后在右侧选择要维护的标签，再编辑最多四级标签、别名、合并／拆分等。已停用标签也可在维护选择器中找到。智能分类主区域保留浏览、分级标签筛选和保存图集，标签维护和新增入口集中到维护页；素材标注仍可从普通图库、检查器和维护页进行。

标签选择、子标签范围和任一／全部匹配在素材筛选栏中合为一个紧凑控件；选择按钮显示“标签”与已选数量，完整路径继续在footer展示，勾选和清空在264px宽的层级菜单内进行。匹配按钮以方形Tag图文表示：Any为实心标签叠空心标签，表示符合任一所选标签；All为两个实心标签，表示同时符合全部所选标签。文字置于图标内，选中时显示实心主题色底和反差文字，切换时底片滑动，悬浮显示中文说明；标签选择、分类树节点、素材标签角标和筛选摘要共用同一标签轮廓。层级图标开关紧邻标签下拉，实心子节点和对勾表示包含子标签，空心子节点表示仅当前标签，悬浮可查看当前含义；选择标签只展开一层树选择器，不再把所有规则收进二次浮层。Footer同步显示所选标签完整路径、匹配方式及子标签范围，内容较长时可以横向查看，并保持素材数量和缩放控件可见。取消新的排除标签条件。父子节点独立勾选，同名标签显示完整路径，下拉支持名称和同义词查找。筛选栏已恢复直接展示媒体类型、喜欢／分析状态、评分、颜色和搜索框的布局，空间不足时自然分行。四种视图使用统一的实心圆角图标，网格／瀑布流／等高行／列表按钮同时可见，智能分类、素材库和我的喜欢共用。纵向瀑布流图标采用两列；文件类型“全部”使用扇形叠放的图片、视频与无外框音符图标。视图、类型、标签匹配等分段按钮切换时，选中背景会平滑滑动；系统开启减少动态效果时直接切换。文件类型切换和其他主要控件统一32px并减少留白；排序字段、升降序和分组合为一个更窄的控件，保留文字选项，时长和时间排序使用各自的分组方式。图库选区仍可通过左侧维护入口带入编辑区。选择图片、视频或音乐时，高级筛选紧跟文件类型切换，与类型控件相距8px；按钮文字和图标跟随主题，展开区域的内边距、组间与字段间距统一8px。标签选择按钮及下拉菜单的主要文字统一12px。

图库左边缘与筛选栏对齐，筛选栏首行上沿与侧栏面板上沿对齐，首行素材与检查器顶部对齐；侧栏到主区域、筛选栏到首排素材、图片排列的横纵间距统一为8px，保留原有列数设置和排列方式。左右滚动条均置于相邻面板的8px缝隙内，不额外挤占菜单或叠加一段空白；检查器关闭时同样保持紧凑。顶栏“导入素材”和旁边五按钮组的外框统一38px高，按钮组与检查器到窗口右缘均为8px。

「动态图集」现称「智能图集」。footer最左侧、素材数量之前提供「＋智能图集」按钮，以主题底色、细边框和加号表示创建动作；左侧入口仍采用文件夹＋放大的四角星图标，顶部不重复显示；悬浮显示说明，弹窗显示冻结的筛选条件；保存后自动打开，且在左侧「智能图集」下直接可见。图集维护只在左侧条目的右键菜单中提供「重命名」和「删除」，不提供管理页或条件编辑。重命名保留全部已保存规则，删除只移除图集记录；删除当前图集后返回智能分类。折叠侧栏中也支持右键和Shift+F10键盘菜单。

图集保存标签、子标签范围、搜索、文件夹、媒体类型、喜欢、最低评分及排序；颜色、分析状态、人物和其他高级筛选暂不支持保存，存在这些条件时弹窗明确提示并禁止创建，避免静默丢失规则。旧版图集的排除条件兼容读取，可在标签筛选栏清除，不再提供新增入口。打开图集时条件回填可见控件，后续筛选立即生效；详情返回保留当前浏览条件。资料库文件不复制、不移动。

单条和批量 AI 分析均可选“同时整理标签”，复用结构化结果，不增加一次视觉模型调用。“整理已有分析”先显示可映射、歧义、新词和缺失结果，确认所选范围后排队。未知的历史来源仍标为未知；可把明确选中的历史映射确认为受保护基线。

“标签建议”按含义和批次分组，来源成员可分页查看；建立新概念与采纳素材关联分开操作。改映射目标也会冻结识别依据，确认前若含义或人工决定变化，需重新预览。合并、拆分、移动、停用和子树排除先核对完整影响；撤销遇到后续编辑会拒绝覆盖。智能图集保存筛选条件，例图只用于寻找候选，确认前不赋标签。

模型与队列在“后台任务”配置；导入分类、Omni 补充、自动补标和自动关系是独立开关，首次均关闭。快速模型使用外置配对 SigLIP2 ONNX，缺模型会等待，无云端回退。开启自动策略还必须有当前模型及概念依据对应的独立人工验证档案，未经验证的结果继续待审。默认保留待审；已拒绝或过期候选的保留期为90天，只有手动预览并确认后才清理，不删除正式标签、人工决定与来源。

当前内存预算仅限制本轮 Python 后端峰值增量，不包含 Omni 子进程，不能作为整机内存硬上限。1.0.15本机安装与数据核验已完成；独立语义准确率和真实资源竞争仍未验收。测试结果见 [实施进度](../.kiro/specs/smart-classification/implementation-progress-2026-10-30.md)。
