# 映屿 · luminisle 使用指南

界面设计与后续 UI 变更统一参照 [UI 规范](UI-SPEC.md)。

## 可选模型与导入整理

图片分析、视频分析、音乐分析、人脸识别、智能分类的模型菜单均可选择「不启用」，视频的独立语音转写也可停用。确认后对应能力不再提交或排入新任务；既有素材、模型文件、标签、人物及分析结果保留。图片和视频即使共用同一个本地模型，也能分别启停。未启用不等于删除上次配置，重新选择实际模型后可继续使用。人脸与分类中因停用而暂停的后台任务会在重新启用后继续受原有模型/素材版本校验约束，不自动创建全库扫描。

三类分析的切换统一显示「云端／本地」，云端在前；音乐云端仍未开放。具体模型名称在模型下拉中选择。

导入拖拽区内的「选择文件」「选择文件夹」是带图标和背景的按钮。下方「导入后自动整理」提供两张卡片：智能分类仅为新入库照片推荐场景/物品标签，不再对新导入视频自动分类；人脸归组可识别照片或视频，勾选后在这张卡片内部选择仅图片、仅视频或两者。范围按钮不会取消卡片勾选。「整理在后台进行，音频不参与」位于标题右侧。每次新开导入都默认不勾选；模型停用时对应卡片禁用，正常文件导入不受影响。当前导入范围调整不清理历史视频标签，也不取消显式分析结果映射等已有能力。

## 快速开始

### 环境要求

- Python 3.12+
- [ffmpeg](https://ffmpeg.org/)（视频压缩、缩略图生成、实时转码）
- [exiftool](https://exiftool.org/)（相机元数据、XMP 写入）

### 安装

```bash
pip install -r requirements.txt
```

### 启动

**方式一：浏览器**（开发调试）

```bash
python3 run.py
```

启动后自动打开浏览器访问 `http://127.0.0.1:6622`。

**方式二：Electron 桌面端**

```bash
cd electron && npm start
```

自动启动后端 Python 进程，窗口大小 1600×900，最小 1000×600。

## 导入媒体

点击左下角"导入"按钮打开导入弹窗，支持两种选择方式：

- **选择文件**：弹出系统文件选择器（支持多选）
- **选择目录**：选择整个文件夹，递归扫描
- 也可以直接将文件或文件夹拖拽到弹窗区域

导入流程自动执行：扫描匹配文件 → 小批次读取元数据 → 每批最多 2 个文件并发准备缩略图和图片相似度特征 → 逐个提交数据库并显示进度。已导入的重复文件会自动跳过；RAW 缩略图优先利用内嵌预览，图片相似度仍使用原有算法。导入窗口只渲染可见的结果卡片，滚动可查看完整结果。

进度包含成功、跳过和失败的文件，只有成功提交数据库的文件才计为“成功导入”。连接中断时已入库的素材保留，重新导入会跳过这些素材。性能对照和验证范围见 [导入性能记录](IMPORT-PERFORMANCE.md)；此优化已随 1.0.10 更新到本地安装版。

> 导入只是将文件信息写入数据库，不会移动或复制原始文件。

## 浏览与筛选

### 详情返回与喜欢照片堆叠

从“我的喜欢”或素材库文件夹打开详情，使用“返回”、Backspace 或浏览器后退，会回到进入前的来源，保留文件夹、筛选、排序、视图、已加载分页、选区与滚动位置。详情内切换上一张/下一张不会改变返回来源；主动点击侧栏则进入所点击的页面。当前会话的返回位置不跨刷新保存。

“我的喜欢”的筛选栏右侧、排列模式按钮旁提供照片堆叠，默认“酷似”，可选择“相似”“聚类”或关闭，档位自动保存。三档沿用查找重复的规则：余弦相似度 ≥0.96、≥0.90、HDBSCAN 同场景聚类，并遵守对应档位已有的排除关系。只对当前筛选命中的喜欢照片分组，视频、音乐和缺少有效特征的照片单独显示；不会自动补算特征、调用 AI、移动或删除原文件。

每组按当前排序选择第一张作为封面，缩略图外显示两层轮廓和照片数量。点击数量或聚焦后按 Enter/空格展开、收起，展开后每张仍可独立查看和操作。收起时组内隐藏照片的选区归到封面，避免误操作看不见的文件。普通点击、右键或删除只作用于实际选中的照片；“全选”仍明确选择当前筛选的全部原始素材。底部素材总数保持原始数量，分页按收起后的封面数量计算。

### 网格视图与列表视图

通过筛选栏右侧的视图切换按钮在两种视图间切换，也可以按 `G` 键快速切换。

- **网格视图**：缩略图卡片，底部滑块控制卡片大小（0.5x ~ 2x）
- **列表视图**：表头固定、可排序的表格形式

### 筛选栏

| 筛选项 | 说明 |
|--------|------|
| 类型切换 | 全部 / 图片 / 视频 |
| 星级筛选 | 点击 1-5 星筛选最低评分 |
| 颜色标签 | 红、黄、绿、蓝、紫五色筛选 |
| 喜欢 | 三态切换：全部 → 已喜欢 → 未喜欢（斜杠标识"排除"） |
| 分析状态 | 三态切换：全部 → 已分析 → 未分析（斜杠标识"排除"） |
| 搜索框 | 全文搜索（文件名 + 分析内容） |
| 排序 | 按导入时间/拍摄时间/名称/分辨率/时长/大小/评分排序 |
| 分组 | 按时间（日/周/月/季/年）或按时长分组显示 |

所有筛选条件、排序、视图模式、文件夹选择自动保存，刷新页面后保持。

> Footer 居中显示当前所有活跃的筛选条件标签，无筛选条件时不显示。

### 选择操作

- **单击**：选中
- **Ctrl/Cmd + 点击**：切换选中
- **Shift + 点击**：范围选中
- **拖拽框选**：在空白区域按住鼠标拖拽，自动框选
- **右键菜单**：查看详情、移除、查找相似、AI 分析、写入 XMP、调整拍摄时间和创建时间

### 右侧检查器

筛选栏最右侧的「检查器」按钮控制显示。单选素材时，小预览、文件名、评分和格式并排显示，下方按文件信息、拍摄与色彩、音频、日期、路径、备注和已有 AI 分析分组；没有记录的参数自动隐藏。「查看详情」和「在文件夹中显示」固定在底部。多选时保留批量分析入口。

图片显示**亮度直方图与 RGB 三通道直方图**，横轴为 0–255。它们根据缓存缩略图的 8 位像素计算，供快速参考，不代表 RAW/HDR 原始数据；不会为检查器额外读取或解码原片。原片离线但缓存仍在时可以查看；缓存缺失时显示不可用与重试。视频和音频继续显示各自参数，不显示图片直方图。

此检查器增强已随 1.0.11 更新到本地安装版。验证记录见 检查器验收（历史 UI 附件已清理） 和 [本地升级记录](local-update-1.0.11-2026-10-24.json)。

### 调整创建时间

选中一个或多个素材，右键选择「调整创建时间」。滑块范围为 **−24 到 +24 小时**，每格 1 小时：负数前移、正数后移，0 时不能应用。偏移以每个文件当前的系统创建时间为基准；打开弹窗后，操作对象固定为当时选中的素材。

点击「应用偏移」后，仅更新原文件的文件系统创建时间（macOS Finder 中的「创建时间」），不会重写照片或视频内容，也不会改动拍摄时间、修改时间、资料库导入时间和标注。没有自动撤销。时间写入精度为秒。

处理结果显示更新、跳过和失败数量。离线或已移除的文件跳过；无权限、文件系统不支持或读回校验失败计为失败，不会当成成功。连接中断时部分文件可能已经更新，应先检查，避免对已成功的文件重复偏移。此功能使用 ExifTool 的系统时间字段；当前验证平台为 macOS。

## 媒体详情

双击画廊中的卡片或选中后按 `Enter` 进入详情页。

### 视频详情

- **元数据栏**：视频信息（分辨率/时长/编码/帧率/码率/色彩空间/色彩曲线）、音频信息、拍摄设备、文件信息
- **视频播放器**：原生 HTML5 播放控件
- **音频波形**：点击波形跳转到对应时间点
- **视频示波器**：波形图（Waveform）、RGB 三通道（Parade）、色度图（Vectorscope），播放时 ~15fps 实时渲染

### 图片详情

- **元数据栏**：图像信息（分辨率/色彩空间/位深）、拍摄设备、文件信息
- **图片预览**：支持缩放（鼠标滚轮/触控板张合）和拖拽平移，缩放范围 25%-500%
- **RGB 直方图**：三通道色彩分布

### 工具栏

返回按钮 | 文件名 | 星级评分 | 颜色标签 | 收藏 | XMP 写入（仅图片）

## AI 智能分析

### 开始分析

**单条分析**：在详情页右侧面板点击"AI 分析"按钮，弹出确认对话框显示当前设置摘要（压缩参数、AI 模型、预估码率），确认后开始分析。

**批量分析**：在画廊中选中一个或多个素材，右键选择"AI 分析"，弹出确认对话框显示：
- 素材总数（视频/图片分别计数）
- 视频/图片分析模型
- 已分析素材数量及处理策略（重新分析 / 跳过）
- 确认后在顶部进度条跟踪所有任务，已提交的素材自动跳过

### 分析流程

**视频分析**（默认多模态模式，3 个阶段）：

1. **视频压缩** — ffmpeg 压缩到设定分辨率/帧率，实时进度条
2. **视频编码** — 完成后显示压缩文件大小
3. **AI 综合分析** — 上传至 AI 服务 → 接收分析结果

**图片分析**（单阶段）：

- AI 图像分析 — 上传至 AI 服务 → 接收分析结果

### 分析结果

分析完成后，右侧面板显示分段列表。每段包含：

- **时间范围**：点击跳转视频到对应时间
- **视觉描述**：AI 对画面内容的描述
- **对话内容**：识别出的语音文字
- **字幕内容**：识别出的字幕
- **镜头维度**：景别、焦段、视角、运镜、透视
- **场景维度**：场景类型、情绪、光线、天气
- **主体/颜色**：识别出的主要拍摄对象和主色调

所有字段均可直接点击编辑，失焦自动保存。

### 删除分段

点击分段右上角的删除按钮，可选择三种删除方式：

- 延长前一段的结束时间
- 延长后一段的开始时间
- 直接删除

## 查找重复

在侧边栏点击"查找重复"进入，基于 ResNet50 视觉特征向量，支持三种相似模式：

- **酷似**：余弦相似度 ≥ 96%，如同张照片的 JPG 和 RAW
- **相似**：余弦相似度 ≥ 90%，如连拍照片
- **聚类**：HDBSCAN 密度聚类，同场景不同角度或时间

可点击"计算特征向量"补全缺失的 embedding。支持右键排除和恢复排除操作。

## XMP 侧车文件

图片完成 AI 分析后，可以点击工具栏中的 XMP 按钮将分析结果写入 XMP 侧车文件（`.xmp`）。写入内容包括：

- 评分、颜色标签
- AI 分析标签（主体、颜色、场景等）
- AI 描述文本

写入的 XMP 数据兼容 Adobe Lightroom / Bridge 等软件。支持在画廊中选中多张图片批量写入。

## 设置

点击顶部工具栏的齿轮图标打开设置弹窗。

### 通用

依次提供「语言」「主题风格」「外观模式」「大模型目录」。四套主题各有亮色和暗色，也可跟随系统；主题及外观模式即时预览、自动保存。

桌面版在「大模型目录」中点击「选择」，指定本地模型加载与下载的根目录，再点「确定」应用到本次运行，无需重新打开应用。切换标签页保留目录草稿，取消不修改目录。默认只修改路径，不复制或删除现有模型。图片、视频、音乐和分类补充共用根目录的 `vlm/<模型ID>/`；人脸列表下载到 `faces/`，快速分类下载到 `classification/`。通过列表下载并选用的模型保留稳定标识，迁移后自动从新根目录定位；未迁移且新目录没有该模型时需要重新选择或下载。手动指定的外部ONNX/图文模型目录继续使用原路径。

目录框下方常驻「同时迁移现有模型」，默认不选；先选择不同的新目录后才能勾选。迁移从本次运行正在使用的根目录复制全部内容，进行SHA-256校验，通过后才保存并应用新路径；弹窗保持loading，显示复制、校验百分比及应用阶段，完成后当前模型清单立即刷新。原文件保留，因此手动配置的独立路径仍可使用，**不是剪切或自动删除旧目录**。目标须为独立空文件夹，不能与原目录互相包含；请在磁盘内新建文件夹，不直接选择磁盘根目录。开始前须等待导入、文件时间调整、分析、创作构思、人脸/分类任务和模型下载完成或停止；切换中阻止新写入。若源/目标被修改、空间不足、复制或校验失败，旧配置不切换；失败副本保留供检查，按错误中给出的位置处理，不会自动覆盖已有文件或反复重试。若服务应用失败，会保留当时配置、副本与日志，不自动还原；应按提示查看日志后重新打开应用。指向根目录之外的软链接须先整理；根目录内的链接会映射到新副本。原根目录内的Hugging Face缓存配置跟随新目录，其他独立缓存或环境变量覆盖保持不变。

目录须为用户配置目录之外的独立文件夹。由 `MEDIA_MANAGER_MODELS` 环境变量指定时，界面只读并提示原因。浏览器版或旧桌面桥接保留目录区块与说明；使用新功能需运行包含新桥接的桌面版本。

## 支持的格式

### 视频

MP4, MOV, AVI, MKV, WebM, M4V, FLV, WMV, 3GP, MTS, M2TS

> 非 H.264 格式（AVI、MKV、MTS 等）播放时自动转码。

### 图片

**常见格式**：JPEG, PNG, WebP, BMP, TIFF

**Apple/HEIF**：HEIC, HEIF, HIF（需 pillow-heif 解码，分析时自动压缩）

### 人物相册（1.0.21）

以下RAW高清缓存与可调归组阈值从1.0.19提供，本机安装与资料库核验见对应版本的交付记录。

在「设置 → 人脸识别 → 人物归组」可调整「自动归组阈值」，默认0.55，范围0.45～0.85，步长0.01。越低越容易归为同一人，也可能错合并。「根据人工纠正校准」默认开启，积累当前模型的合并、拆分、确认或不同人反馈后，在手动值上下0.05内调整；撤销对应操作后不再参考其反馈。关闭后使用手动值；修改不会自动合并已有相册或清空队列。详细规则可点旁边问号查看。

NEF等RAW在导入、在线预览或人脸扫描时保留可用的高清缓存。原片离线时有高清缓存仍可预览和识别；只有旧320px缩略图时需要连接原片，不能通过放大恢复细节。连接后，在人物扫描里选择相关文件夹和「重新扫描（保留人工纠正）」以刷新已有低清头像与识别结果。详情加载失败可点「重新读取」。

1.0.22起：「人物 → 待核对」右上角可点「全量重新扫描」，先查看去重素材数，再确认开始。范围包含全部分页的待确认人脸及可能同一人建议所关联的素材，不扫描无关素材；正在识别的不会重复添加。命名、合并、纠正及旧结果保留，任务到Header后台入口管理。普通照片也不再用离线的低清网格缓存识别人脸；离线且无高清预览的会等待，连接移动硬盘后在Header点「重试」。

1.0.23已更新本机：视频同一可信出镜轨迹的代表脸先综合判断身份，减少一人被逐帧拆成多个人物；特征或已有归属冲突时显示「出镜待核对」，候选身份不明确时显示「归属待核对」。人工姓名、归属与排除保留，历史拆分的人物不会被自动合并。升级核验后已按用户要求继续原暂停识别队列，没有额外发起全量重扫。

左侧「人物」提供全部人物、待命名、待核对和已隐藏，各子项配有相应图标。点头像进入人物图集，继续使用已有喜欢、内容标签和文件夹筛选；检查器中的「此素材中的人物」可修正认错、拆出新人物或手动关联背影/遮挡照。合并先预览，人工决定冲突需先处理；保存后可撤销，若成员后来发生变化会提示冲突。重名可保留两个独立人物。

1.0.21已将双列人脸核对界面更新到本机：「待确认人脸」每行两张卡片，左侧大图、右侧并排标明当前归属与建议归属，窄窗口自动单列。画质不足且无法归组时显示「尚未归组」，没有候选则显示「暂无建议」。点击「纠正」在按钮旁打开头像面板，搜索姓名、点头像选择人物，再点「确认纠正」保存；也可新建人物、暂不归组、标为非人脸或确认当前归属。检查器和批量纠正使用同样的头像选择方式，原有撤销保留。打开原素材查看后返回，仍停留在原核对类别与页码；单纯查看或点选头像不会修改归属。

首次还没有人物时，主区域用九张照片组成的3×3网格演示整理过程：圈出人脸位置、找出五官特征，再将同一人物的照片合为三组堆叠。下方只保留三个简短步骤，并随动画高亮。点击「开始人脸识别」打开与右上角相同的识别范围弹窗，选好范围并确认后才创建任务；旁边保留「人脸识别设置」。减少动态效果或动画不可用时，保留整理后的静态人物堆叠和所有操作。搜索无结果、已隐藏和暂无待核对项目保留各自提示。

开发版在「设置 → 人脸识别」上方选择InsightFace的Buffalo L/M/S/SC或Raccoon L/S。已安装套装自动带入整组文件，未安装时点击组合列表右侧下载。下方三张卡片只读展示阶段、模型名、实际文件名及状态，不再提供独立模型下拉、路径输入、文件选择或阶段下载。Buffalo默认关闭复核，Raccoon默认开启；套装没有复核文件且无历史配置时开关禁用，Raccoon可按需关闭再启用。核验只检查当前文件接口，确认设置后生效。切换另一套装清空旧引用，下载自动填入整组；历史外部/自定义配置继续可读，不在未操作时删除。根目录在「设置 → 通用」修改，下载弹窗中的faces/套装文件夹不能覆盖已有目录。权重不随安装包分发，保存设置不会自动扫描。兼容与许可见[人脸扫描配置](PEOPLE-SCANNING.md)。

导入弹窗可按次勾选「导入后在后台识别人脸」，再选择「仅图片／仅视频／两者识别」。每次新开导入默认不勾选，类型恢复为两者识别；所有文件照常导入，范围只控制本次后台人脸任务，音频不参与。人物页「人脸识别」可选择所选素材、多个素材库文件夹（勾选父目录会同步勾选所有子目录；可单独取消子目录，父目录变为半选，扫描范围也同步排除；范围自动去重），或整个素材库（仅包含已导入的照片与视频，无需再次勾选确认）；对已识别素材选择「跳过」或「重新扫描（保留人工纠正）」。清晰的新人物与明确匹配自动归组；存疑匹配、无法归组的低质量脸进入待核对。命名是独立操作，无需审核每一张清晰人脸。

在「设置 → 人脸识别 → 视频人脸识别」选择1、2、3帧/秒，默认1帧/秒，点击确认后保存；取消不改配置。帧率越高，采样越密，耗时通常越长；任何档位都可能漏掉短暂出镜。该设置独立于视频分析帧率，修改不会自动扫描或影响照片任务，已完成视频需选择“重新扫描”才按新帧率处理。

1.0.24已更新本机，新增「视频压缩」：1080p默认按比例缩小，不放大小视频；原片使用源分辨率。它只影响视频人脸识别，与视频AI分析分辨率独立。处理时实时解码和缩放，不生成压缩视频文件，也不修改原片；确认后对未完成任务生效，已完成结果需主动重新扫描。选择器旁信息按钮可查看说明。本次升级已按用户要求用默认1080p继续原暂停识别，没有额外发起全量重扫。

同组的「每次出镜取样数」可设为1～48张，默认4张；点击旁边的小问号可查看轨迹含义、如何跟踪和怎样选图。这是每条连续人脸轨迹用于提取特征和复核的代表样本数量上限，不是整个视频的检测帧数；合格样本不足时可能更少。提高数量会增加计算与候选缓存，不保证识别精度一定提高。确认保存、取消丢弃草稿；不影响照片任务，已完成视频仍需明确重新扫描才更新。

点击「开始识别」排队成功后，弹窗自动关闭。右上Header的后台进度入口同时显示AI分析与人脸任务；点击后可暂停、继续、重试或停止人脸识别，在其他页面也能操作。弹窗和人物Footer不再管理任务。停止只取消未完成任务，不删除人物、已识别结果或原素材。导入、播放和前台分析优先；缺模型、原片离线、质量不足、未检测到脸和失败分别显示。视频从完整时间轴按所选帧率直接选取原帧并光流跟踪，在切镜头和新运动时补检，每条轨迹按设置上限选取清晰代表人脸提取身份特征（默认4张）。保留原时间戳，不生成重复补帧；帧间隔本身不会强制断轨。1.0.24起使用上述独立视频压缩选项，不沿用「视频分析」的分辨率、压缩/抽帧率或每窗预算；完全本地，不上传视频，也不输出完整视频副本或采样JPEG。展示实际代表帧时点，不提供尚未验证的连续出场区间；未检出不能解释为人物没有出现。取消或前台抢占会释放视频工作进程，继续时从该视频开头重新处理。新模型切换保留姓名和人工决定；旧任务需选择“重新扫描”才使用新跟踪流程，默认“跳过”保留原结果。

完整迁移副本保留姓名、人工关联/排除和人物数据，以及资料库内的 `people-cache/`、`raw-previews/`；模型继续从外部目录加载。1.0.19已替换本机并核验原资料库全部48张表，已有暂停队列原样保留，继续扫描由用户操作。新增RAW与校准功能已通过合成数据及冻结包检查；真实NEF清晰度与身份准确率仍需原片联机后复核。

### 智能分类（1.0.15）

本机现已预置「场景、主体、活动、视觉特征」四大维度，共1,107个节点、最多四级、153个同义表达。旧的两个无引用扁平标签已按用户要求移除。词库不会在启动时覆盖用户改动，也不会因此给旧素材自动打标签；完整层级见[默认标签树说明](DEFAULT-TAXONOMY.md)。

“智能分类”在左侧只展开分类树，不附加查找、隐藏空分类或内层滚动；所有展开项共用侧栏最外层滚动。“标签树维护”左侧只保留一级入口；开发版主区域内左侧常驻可展开的标签树、右侧编辑最多四级标签、别名、合并／拆分等，已停用标签也保留在树中。智能分类主区域保留浏览、分级标签筛选和保存图集，标签维护和新增入口集中到维护页；素材标注仍可从普通图库、检查器和维护页进行。

导入弹窗可独立勾选「导入后在后台快速分类」，每次新开默认关闭；仅对本次新入库照片登记任务，视频和音频不参与。是否勾选人脸识别不影响分类选择。旧全局classification_enabled不再控制导入；历史未分类素材仍可显式发起后台分类。

开发版的模型、空闲精补、词库关系整理、时间/内存预算、自动应用和建议保留期放在「设置 → 智能分类」。快速分类只列Google SigLIP 2的17种规格，不再提供自定义或单独JSON选择；选定规格后由下载流程配置配对图文模型。Base共6种（/16的224/256/384/512、/32的256、/16 NaFlex）；Large共3种（/16的256/384/512）；So400m共6种（/14的224/384、/16的256/384/512、/16 NaFlex）；Giant-opt共2种（/16的256/384）。本地二次补充与AI词库整理仍共用另一组模型，默认Qwen3-Omni 30B-A3B，复用图片/视频服务。下载完成仅填入未改动的当前草稿，确认后保存，迟到结果不覆盖新草稿。已有外部配对目录仍可读取，无须重设或迁移。分类使用缓存预览，视频仅封面，不能等同整段视频理解。后台任务、审核、保留策略不变。

17种快速分类模型的原始厂商为[Google](https://github.com/google-research/big_vision/blob/main/big_vision/configs/proj/image_text/README_siglip2.md)。15种固定分辨率ONNX来自[ONNX Community](https://huggingface.co/onnx-community)，2种NaFlex使用[upshift的完整配对导出](https://huggingface.co/upshift/siglip2-base-patch16-naflex-onnx)。固定版本、体积、SHA-256和接口写入后台清单；下载FP32图片/文字编码器、tokenizer和需要的外部数据，取消或失败只清理本次下载，不覆盖已有文件。无需PyTorch，不自动下载全部规格。17种规格已用小型合成ONNX验证实际加载/推理契约；除历史Base/16-224实验外，没有全量下载真实权重，也未重测各规格的速度或识别准确率。

标签选择、子标签范围和任一／全部匹配在素材筛选栏中合为一个紧凑控件；选择按钮显示“标签”与已选数量，完整路径继续在footer展示，勾选和清空在264px宽的层级菜单内进行。匹配按钮以方形Tag图文表示：Any为实心标签叠空心标签，表示符合任一所选标签；All为两个实心标签，表示同时符合全部所选标签。文字置于图标内，选中时显示实心主题色底和反差文字，切换时底片滑动，悬浮显示中文说明；标签选择、分类树节点、素材标签角标和筛选摘要共用同一标签轮廓。层级图标开关紧邻标签下拉，实心子节点和对勾表示包含子标签，空心子节点表示仅当前标签，悬浮可查看当前含义；选择标签只展开一层树选择器，不再把所有规则收进二次浮层。Footer同步显示所选标签完整路径、匹配方式及子标签范围，内容较长时可以横向查看，并保持素材数量和缩放控件可见。取消新的排除标签条件。父子节点独立勾选，同名标签显示完整路径，下拉支持名称和同义词查找。筛选栏已恢复直接展示媒体类型、喜欢／分析状态、评分、颜色和搜索框的布局，空间不足时自然分行。四种视图使用统一的实心圆角图标，网格／瀑布流／等高行／列表按钮同时可见，智能分类、素材库和我的喜欢共用。纵向瀑布流图标采用两列；文件类型“全部”使用扇形叠放的图片、视频与无外框音符图标。视图、类型、标签匹配等分段按钮切换时，选中背景会平滑滑动；系统开启减少动态效果时直接切换。文件类型切换和其他主要控件统一32px并减少留白；排序字段、升降序和分组合为一个更窄的控件，保留文字选项，时长和时间排序使用各自的分组方式。图库选区仍可通过左侧维护入口带入编辑区。选择图片、视频或音乐时，高级筛选紧跟文件类型切换，与类型控件相距8px；按钮文字和图标跟随主题，展开区域的内边距、组间与字段间距统一8px。标签选择按钮及下拉菜单的主要文字统一12px。

图库左边缘与筛选栏对齐，筛选栏首行上沿与侧栏面板上沿对齐，首行素材与检查器顶部对齐；侧栏到主区域、筛选栏到首排素材、图片排列的横纵间距统一为8px，保留原有列数设置和排列方式。左右滚动条均置于相邻面板的8px缝隙内，不额外挤占菜单或叠加一段空白；检查器关闭时同样保持紧凑。顶栏“导入素材”和旁边五按钮组的外框统一38px高，按钮组与检查器到窗口右缘均为8px。

「动态图集」现称「智能图集」。footer最左侧、素材数量之前提供「＋智能图集」按钮，以主题底色、细边框和加号表示创建动作；左侧入口仍采用文件夹＋放大的四角星图标，顶部不重复显示；悬浮显示说明，弹窗显示冻结的筛选条件；保存后自动打开，且在左侧「智能图集」下直接可见。图集维护只在左侧条目的右键菜单中提供「重命名」和「删除」，不提供管理页或条件编辑。重命名保留全部已保存规则，删除只移除图集记录；删除当前图集后返回智能分类。折叠侧栏中也支持右键和Shift+F10键盘菜单。

图集保存标签、子标签范围、搜索、文件夹、媒体类型、喜欢、最低评分及排序；颜色、分析状态、人物和其他高级筛选暂不支持保存，存在这些条件时弹窗明确提示并禁止创建，避免静默丢失规则。旧版图集的排除条件兼容读取，可在标签筛选栏清除，不再提供新增入口。打开图集时条件回填可见控件，后续筛选立即生效；详情返回保留当前浏览条件。资料库文件不复制、不移动。
