## 布局

- 智能分类的左侧展开区只展示完整标签树，空分类保持可见；取消树内搜索、隐藏空分类控件及树的高度/滚动限制。素材库、人物、分类和构思共用侧栏外层滚动。
- 标签树维护只保留左侧一级入口。标签选择与内容维护集中在右侧；选择器包含已停用节点，仍可维护和恢复。
- 智能分类主区域只保留浏览与筛选，不显示维护词库或标注操作。普通图库、检查器及维护页继续提供素材标注能力；从图库点击左侧维护入口会携带明确选区。
- 动态图集由维护页的“动态图集”标签页统一打开、编辑条件、删除；智能分类仍可保存当前筛选为图集。

## 层级选择组件

`TaxonomyTagPicker` 在分类筛选、普通图库标注、维护表单、动态图集、候选映射和人物组合筛选中共用。

| 属性 | 含义 |
| --- | --- |
| modelValue | 单个标签ID或多个标签ID；一级父级可为null |
| multiple | 多选，父子节点严格独立，不级联勾选 |
| options | 该表单允许的候选；默认使用可分配标签 |
| label | 可见说明及按钮名称；也支持逐素材aria-label |
| disable | 禁止交互并关闭已有浮层 |
| clearable | 单选允许清除；多选通过标签移除及清空选择 |

通过 `update:modelValue` 更新值，不进行网络写入。筛选祖先会保留为不可选上下文；下拉搜索保留树层级及名称/同义表达匹配。搜索范围外的已选项不因勾选变化被丢弃，同名叶子显示路径。未收录的旧条件仍可移除，新拆分目标的临时ID也保留。

按钮、标签与浮层使用现有主题变量、圆角与焦点样式；临时浮层内只有一个滚动容器。键盘可通过按钮、树和复选框操作，Escape关闭浮层；导航变化也会关闭旧浮层。空结果提供状态提示。组件不修改共享节点数据或自动清理旧筛选条件。

## 验证

新增 `tests/taxonomy-picker-regressions.cjs` 检查层级、同名ID、别名、不可选祖先、搜索后保留选择、一级父级、临时目标及禁用状态。

`tests/taxonomy-layout-browser.cjs` 使用独立合成库验证纯树、实际滚轮、分级包含/排除、维护入口、选区传递、动态图集及四主题亮暗和窄窗口。证据保存在 `build/taxonomy-layout-validation/`。原人物浏览器回归17组通过，正常路径无页面/控制台错误和失败请求；原分类状态30项与图库导航13项也通过。

最终布局专项10组、外观与故障恢复38组、人物17组、原标签维护流程4组均通过。外观专项含预期503与离线注入，正常路径无页面/控制台或网络错误；移除维护侧栏树后，目录读取失败提示与重试已迁入右侧。独立临时服务、合成库及连接文件已清理。汇总：验证记录（历史 UI 附件已清理）。
