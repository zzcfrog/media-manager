# 本地 Omni 标签与词表扩充实测 · 2026-10-30

已用 Qwen3-Omni-30B-A3B-Instruct 完成同一批 128 个缓存预览的识别：照片 96 张、视频封面 32 张。逐张验证缓存 SHA256，与此前 CLIP ViT-B/32、SigLIP 2 Base 对照一致；本轮复用这两款模型的既有结果。未读取原片、上传媒体或调用付费接口。

Omni 使用本机已有的 Q4_K_M 权重及 Q8_0 视觉投影，通过 llama.cpp b10451 / Metal 顺序运行，context 8192、parallel 1、8 CPU 线程、temperature 0、seed 42，关闭思考。机器为 M3 Max / 48 GiB。输入包含图片、固定 100 类的中英文名称和结构化输出要求，不提供文件名、路径或拍摄信息。

每张图从固定词表选 0～5 个类别，另外可提出最多 3 个具体中文新词、建议父类和简短可见依据。128 张全部返回有效结构，无重试。这里的固定 100 类是实验候选词表，不能等同于生产标签库；另以只读接口检查了生产中 2 个已有手工标签名称，候选未与它们发生同名冲突。

| 请求耗时 | 结果 |
| --- | ---: |
| 平均每张 | 2.761 秒 |
| 中位数 | 2.706 秒 |
| P95（排序样本位置法） | 3.368 秒 |
| 128 张请求耗时之和 | 353.364 秒，约 5 分 53 秒 |

上述时间包含固定标签选择、新词生成及依据输出，排除模型加载、页面制作和人工检查。最初独立启动加载约 32.26 秒；之后操作系统缓存已热时重启约 3.03 秒。此任务比 CLIP / SigLIP 的固定词表向量匹配多了文本生成，耗时不可直接当作同一工作量的性能排名。

126 张图提出额外候选，规范化名称精确去重后共 194 个，其中 54 个名称由多张图独立提出；过滤 44 条与既有词表或同图重复的额外建议。仅做名称去重，没有把同义词、相近粒度或父类关系自动视为正确。所有新词状态均为待审核，没有写入生产标签库。

先导 3 张测试发现，将未经审核的新词加入后续图片的提示词会影响后续输出。因此正式 128 张均独立识别，逐张登记实验候选，但不把候选反馈给后续图片。先导记录单独保留，不计入正式结果。

三款模型首选完全一致 30 张；Omni 首选与另外两款均不同 73 张。这些是模型间一致性，不能作为准确率。新词存在同义重叠、粒度和父类建议不合适的问题；部分依据带有推测措辞，页面已标记待复核。没有人工真值，不能据此认定某模型更准确。

独立只读对照页并排展示图片、三模型标签、新词、建议父类和依据，支持 Top5/Top10、分歧及媒体筛选、搜索、分页、放大和两份 CSV 下载。展开新词库后可点击词条查看来源图片。私人预测、文件名、来源关系、CSV 和服务地址均保留在 Git 忽略的 `build/omni-label-review-2026-10-30/`；本报告不包含私人素材或访问地址。服务只监听 loopback，限定 Host 与资源白名单，无写入接口。

验证覆盖全部 128 个图片接口和缓存哈希、预测和候选引用、CSV 行数、HTTP 访问边界及浏览器交互；浏览器无错误或警告、无横向溢出，用户页面图片正常显示。完整结果 CSV 为 3,446 行，新词 CSV 为 195 行，均包含表头。

这验证了“单次识别同时提出新标签、立即登记候选”的可行性；正式词库仍需同义归并、父类校验和审核机制。本轮只识别视频封面，未评估视频全内容、外接盘原片解码、后台与导入竞争资源、长期队列或自动正式入库。模型测试进程已停止，模型文件大小、修改时间及 inode 未改变；保留只读服务和结果供用户查看。
