# UE Design — 视频分析器

## 整体风格

- **桌面优先**的 Electron 应用，无移动端适配
- **暗色主题**为默认，支持亮色和跟随系统
- 8 种可选主题色（accent），默认蓝紫 `#6c8cff`
- Quasar 组件库，圆角卡片（16px），毛玻璃对话框（backdrop-filter: blur）
- Lottie 动画用于 AI 分析的等待状态

## 主题系统

三种模式：暗色 → 亮色 → 跟随系统。通过顶部工具栏调色板按钮切换。

| 变量 | 暗色 | 亮色 |
|------|------|------|
| `--bg` | `#0a0a0a` | `#f5f5f5` |
| `--surface` | `#141414` | `#fff` |
| `--text` | `#e8e8e8` | `#222` |
| `--accent` | 用户可选 | 用户可选 |

可选主题色：蓝紫、浅蓝、青色、绿色、琥珀、深橙、红色、紫色。

## 页面结构

### 导航

Hash 路由，无 Vue Router：
- `#/gallery` — 媒体库（默认）
- `#/favorites` — 喜欢筛选
- `#/detail/:id` — 媒体详情
- `#/workbench/:id` — 创作工作台

Gallery 使用 `<keep-alive>` 缓存状态，Detail 每次进入重建。

## Gallery 页面

### 筛选栏

顶部水平排列，flex-wrap 自动换行：

| 控件 | 说明 |
|------|------|
| 类型切换 | 全部 / 图片 / 视频 / 音乐（`q-btn-group` + 独立 `q-btn`，各带 `q-tooltip` 1s 延迟）；切换类型不再自动展开面板，只刷新 facets，详见下节 |
| 星级筛选 | 1-5 星，点击切换 |
| 颜色标签 | 5 色圆点（红黄绿蓝紫），点击切换 |
| 收藏 | 三态：全部 → 已喜欢 → 未喜欢（CSS 伪元素斜杠标识"排除"），循环切换 |
| 已分析 | 三态：全部 → 已分析 → 未分析（CSS 伪元素斜杠标识"排除"），循环切换 |
| 重置 | 有激活筛选时显示，重置所有筛选和搜索条件 |
| 搜索框 | 全文搜索（文件名 + 分析内容） |
| 排序 | 下拉选择 + 升降序切换 |
| 分组 | 按时间/时长分组（排序字段为时间时可用） |
| 视图 | 网格 / 列表 切换 |

### 高级筛选面板

**按钮**：筛选栏内一个「高级筛选」按钮（icon `tune` + 尾部 expand_less/expand_more 箭头，仅当当前媒体类型有维度时显示）。三态：收起无筛选 = 普通态；收起有筛选 = `adv-btn-active`（accent 高亮）；**展开 = `adv-btn-open`**（accent 色 + **透明底** + 底部方角），展开时按钮与面板**同底色融合连通**——Office 选中「开始」页签式：按钮即面板的页签，**栏 + 面板整块同用 `--surface` 底**（较页面底深一档：暗 #141414 / 亮 #fff，与媒体卡片同层级——整块 ribbon 区肉眼可辨；filter-bar 恒 surface 底，收起时即一条工具栏，展开无底色跳变），零线零色差连成一块，按钮透明底露栏底、仅以 accent 文字示选中；栏底边随 `adv-open` 透明，面板底边 1px `--border` 即整个 ribbon 区外缘；收起后恢复栏底边（面板消失）。点击展开**独占一行**流式面板；`advPanelOpen` 随 `_saveFilters` 持久化，切换媒体类型不自动展开（只刷新 facets）。

**筛选条件 = Office Ribbon 同屏组段**（spec `group` 键，像 Office「开始」页签内部样式）：每个分组占一块**组段**——段底居中 10px 小字组名，段内维度下拉**固定上下两行**（grid 列数 = ⌈维度数/2⌉，选项全留在下拉里，不平铺），**段间 1px 竖分隔线**（首段无边线）。段为固定形状块（不收缩），**组段恒单行排布**——放不下不折行，面板**横向滚动**（滚轮竖转横 + 按住拖拽滑动 + 触控板横扫，6px 细滚动条）。下拉有值时隐藏三角、小 × 靠右独占（见交互）。字段**定宽四字宽**（下拉 120px = 图标 + 四个中文字；日期范围文本 176px），超宽值 ellipsis 截断；每维下拉左侧 **14px 维度语义小图标**（灰 text3，active 变 accent），一眼可辨维度含义。

| 媒体类型 | 组段（段内维度，段底组名） |
|------|------|
| 图片（5 组 19 维） | **镜头语言**（景别·焦段·视角·透视·景深·构图）· **场景光线**（场景·光线·天气）· **风格色调**（风格·色调·影调）· **画面内容**（颜色·主体）· **相机与文件**（编码·相机品牌·相机型号·方向·拍摄日期） |
| 视频（5 组 18 维） | **镜头语言**（景别·焦段·视角·运镜·透视）· **场景光线**（场景·光线·天气）· **画面内容**（情绪·颜色·主体）· **相机**（品牌·型号）· **技术参数**（方向·分辨率·帧率·时长·色彩空间）；**任一片段命中即视频命中**（多片段 EXISTS 语义） |
| 音乐（1 组段 + 显示） | 显示（封面/波形，`.engine-toggle` 药丸，displayOnly，无组段名/无边线）· **音乐特征**（情绪·曲风·乐器·使用画面·人声，词表 en 值 + zh 显示） |

**拍摄日期 = 合一范围控件**：单个只读输入（placeholder「拍摄日期」空态居中，同其他维度），点框内日历图标弹 QDate **range 范围选择**（第一击起点不提交、第二击终点提交并自动关弹层），框内显示 `from ~ to`；尾部 **× 图标一键清空两端**（Quasar clearable 对 readonly 不渲染 ×，故自定义）。

**字段**（34px，Quasar filled 半透明叠层底）：空值时维度标题**全宽水平居中**（居中基准 = 整个控件，视觉为占位符；仅聚焦未选时上浮 10px 小标签兜底）；**有值时不再显示维度名，值垂直+水平居中**（`padding-left:2px` 对冲左右图标区宽度差，与空态标题同一视觉中心；日期范围文本同样居中）。**有选中值的下拉强调显示**：accent-dim 底 + accent 2px 底条 + accent 值文字，与未选过的下拉一眼区分。

**下拉菜单**（`adv-select-menu`，portal 到 body）：紧凑规格——8px 圆角 + 3px 内边距 + 28px 行高选项（12px 字号），**宽度保底 168px**（不随四字宽字段收窄；Quasar 会给菜单设内联 min-width = 锚点宽，需 `!important` 对冲）；选项右侧**独立计数徽标**（10px 胶囊，非 label 拼接）；选中项 accent-dim 底 + accent 字 + 对勾图标；0 计数置灰（opacity .45）不可点（facets 未加载时不禁用，加载后响应式补计数）。选项来源：视觉枚举维度 = **标准枚举 + 并入数据新值**（带计数）；音乐维度 = 词表（`root.musicTax`）；动态维度（颜色/主体/相机/色彩空间）= facets 数据。

交互：
- 下拉有值时**隐藏下拉三角、只显示 14px 小 × 靠右对齐**（右缘与空态三角右缘一致；hover 变 accent，点击清空；清空后恢复三角）；日期控件同款 × 清空，无需独立清除按钮
- 活跃维度出现在 Footer 筛选条件标签（日期显示 `拍摄日期: from ~ to`；音乐值显示 zh 标签）
- 音乐「显示」切换立即生效且持久化（不触发列表重载、不参与 disable 判定）；其余维度触发重新筛选
- 重置按钮（`filter_list_off`）一键清空所有筛选（含媒体类型回「全部」）并收起面板
- 维度计数来自 `GET /api/library/facets`（仅按媒体类型作用域，不含交叉筛选；会话内导入新文件后刷新页面即更新）

### 网格视图

CSS Grid 自适应列数，卡片宽度通过底部滑块控制（0.5x ~ 2x）。可按时间线分组显示。**50% 缩放时隐藏卡片文字（文件名、元数据），进入紧凑模式只显示缩略图和叠加信息**。使用 `content-visibility: auto` 优化大列表渲染性能。

**卡片内容**：
- 16:9 缩略图（音频卡**封面优先**：有内嵌封面显示封面、无封面回落波形；封面以 `object-fit:cover` 居中裁剪，正方形封面不 contain 留黑边）
- 类型图标（视频/图片，右下角）
- XMP 徽章（图片已写入 XMP 时，右下角类型图标左侧，显示自定义 SVG 图标）
- AI 分析徽章（已完成分析时，左下角）
- 喜欢红心
- 颜色圆点
- 星级
- 文件名、分辨率/相机/时长

### 列表视图

表头固定，可排序。每行显示 64x36 缩略图 + 文件名 + 分辨率 + 时长 + 大小 + 拍摄日期 + 导入日期 + "标记"列（评分 + 颜色标签 + 收藏 + 分析状态）。音频行缩略图同卡片封面优先规则（封面/波形随筛选档切换）。

### 导入流程

三步弹窗：

1. **选择**：拖拽区域 + "选择文件" / "选择目录" 按钮（Electron 原生对话框）
2. **进度**：扫描文件 → 3 个并发导入 → 线性进度条 + 已导入缩略图网格
3. **完成**：导入数、跳过数（重复）、失败数 + 可展开详情列表

## Detail 页面

### 布局

双栏布局，元数据信息显示在媒体上方：

```
┌──────────────────────────┬─────────────────────┐
│  工具栏（返回、文件名、评分、颜色、收藏、XMP）          │
├──────────────────────────┤                     │
│  元数据横排栏（图像/视频·音频·拍摄设备·文件信息）       │
├──────────────────────────┤                     │
│                          │  分析结果            │
│     视频播放器 / 图片预览  │  （分段列表 /         │
│     （图片支持缩放拖拽）    │   分析进度）          │
│                          │                     │
├──────────────────────────┤                     │
│  音频波形                 │                     │
├──────────────────────────┤                     │
│  Waveform │ Parade │ Vec │                     │
└──────────────────────────┴─────────────────────┘
       flex: 1                     420px 固定
```

- 元数据栏：横排显示多个区块（图像/视频、音频、拍摄设备、文件信息），每个区块带标题和左侧强调色竖线
- 视频元数据栏：视频信息分两列（左列：分辨率/时长/编码，右列：帧率/码率/色彩空间/色彩曲线）
- 色彩曲线：显示 PictureControlName（尼康 N-Log 取自 EXIF，大疆 D-Log M 从文件名推断），带叹号提示准确性说明
- 图片预览：支持缩放（鼠标滚轮/触控板双指张合）和拖拽平移（触控板双指滑动/鼠标拖拽），缩放条贴在图片底边内侧
- **全屏看图**：F 键或点击缩放栏全屏按钮，浏览器 Fullscreen API 全屏显示图片区域，Escape/F 退出
- **导航缩略图（Minimap）**：放大 > 100% 时右下角出现半透明缩略图（160px 宽），蓝色矩形显示当前视口位置，点击可跳转
- 文件路径：完整显示，超长时在文件信息区块内折行

### 工具栏

- 返回按钮 → `#/gallery`
- 文件名标题
- 星级评分（1-5 星，可点击）
- 颜色标签（5 色圆点）
- 喜欢按钮
- XMP 写入按钮（仅图片 + 已分析完成时显示）：未写入时显示写入图标（文件+箭头），已写入时显示刷新图标（文件+循环箭头）

### 元数据面板

横排显示在媒体上方，分为 3-4 个区块（视频4块：视频·音频·拍摄设备·文件信息；图片3块：图像·拍摄设备·文件信息），每块标题带左侧强调色竖线。前三块固定宽度不收缩，最后一块（文件信息）自适应剩余空间。

### 视频播放器

原生 HTML5 `<video>` 控件，下方三个 Canvas：

1. **音频波形**（64px 高）：点击跳转，播放时带动画游标
2. **Waveform Scope**：亮度分布
3. **Parade Scope**：RGB 三通道波形
4. **Vectorscope**：色度圆形分布图

播放时以 ~15fps 实时渲染。图片显示 RGB 直方图。

### 设置弹窗

点击顶部工具栏设置图标打开，**标签页布局**（4 个标签：通用 / 图片分析 / 视频分析 / 剪辑构思，**全部常驻渲染**——tab 不随引擎/多模态切换增删，位置固定不动），底部"确定"按钮保存。弹窗**固定宽度 480px**、面板**固定高度 560px**（切 tab / 切引擎尺寸均不变；2026-08-18 从 440 调高——视频页并入语音分析子模块后 440 装不下；面板用 `.settings-panel` 类且**子项 `flex-shrink:0`**——此前 flex 列布局下超高内容会压缩变形而非滚动，这正是「组件被遮挡」的根因）。

**视觉体系**（2026-08-17 重构，2026-08-18 两轮调整：引擎药丸化、标签外置）：⓪ **字段标签在控件外**（`.settings-label` 11px 灰字置于 filled 控件上方，控件内只显示值——替代 Quasar filled 的盒内浮动标签，消除「标题缩在灰盒里」的紧凑感，各控件值基线统一水平对齐；两列行内各自带标签）；① 引擎选择 = **药丸式切换**（q-btn-toggle 紧凑型：内容自适应宽度 ~245×31、999px 圆角胶囊描边容器、选中项半透明强调色底 + 强调色字——不再是通栏大色块），图片引擎/视频引擎/语音引擎三处同构；② **小节标题** = 12px 加粗 + 左侧 3px 强调色竖条（与快捷键弹窗同款），用于「抽帧参数」「语音分析（Omni 模式）」分组；③ **提示信息** = 无底色的安静旁注（11px text3 字 + info/hourglass/downloading/error_outline 图标 + 左侧 2px 灰细竖线）——**不用灰底**（filled 输入控件同为灰底，会误导可点击），每模式至多一条、置于块底部；④ 间距统一 14px，下载进度/错误也进提示框体系。

**通用**标签页：
- 语言选择：下拉菜单（中文 / English），切换后全页面即时更新
- 主题模式：暗色 / 亮色 / 跟随系统
- 强调色：8 种主题色圆点选择（蓝紫、浅蓝、青色、绿色、琥珀、深橙、红色、紫色）

**图片分析**标签页：

### 时间线工具栏

底部面板工具栏左侧新增 **[时间线] [脑图]** 切换按钮（`q-btn-toggle`，accent 高亮选中态）。切换时保持数据不变，仅切换展示方式。

时间线模式下工具栏包含四组功能：

- **播放控制**：跳到开头 / 播放暂停 / 跳到结尾 / 倍速选择（0.5x-2x），联动预览区视频播放器
- **编辑操作**：撤销 / 重做（快照栈，时间线/脑图两视图通用，脑图编辑也可撤销）；删除（需选中轨道项，右键菜单或 Delete 快捷键）
- **缩放**：缩小 / 滑块（1-10x）/ 放大 / 适配宽度，通过 scaleX 放大轨道内容
- **添加轨道**：下拉菜单选择轨道类型（主题/情绪/旁白/字幕/文字/视频）

**行头冻结**：左侧行头（`.wb-track-label`，60px 宽）使用 `position: sticky; left: 0`，横向滚动时间线时六个轨道标签 + 标尺左侧空白固定不动，轨道内容在其后滚动。playhead（z-index 10）始终在行头（z-index 6）之上。

**片段缩放联动**：拖拽调整 video 片段左右边缘时，落在该 video 原时间区间内的 emotion/旁白/字幕/文字块会按比例同步缩放（缩短则等比缩短、拉长则等比拉长），保持各轨道块与所属 video 段对齐。

**非视频块编辑约束**（保持脑图与时间线一致）：情绪/旁白/字幕/文字/主旨等非视频块**不能手动拖边缘改时长**（鼠标在边缘不显示缩放光标、不进入缩放，时长随所属 video 片段被动联动）。**删除主旨或叙述块**会弹窗确认，确认后连同其下所有叙述/镜头一并删除。

**主旨/叙事 overlay 框**（对齐脑图层级）：时间线不是 6 条平行轨道，而是嵌套两层——
- **情绪轨道**独立在最上（情绪曲线 + 点），**不被框覆盖**（情绪是分镜元数据，不分组）。
- **内容组**（情绪下方）：旁白/字幕/分镜 3 条贯穿平行轨道。
- **主旨框**（覆盖框）：横跨整个主旨时长、纵向包住 3 条内容轨道，彩色实线边框 + 标题。
- **叙事框**：在主旨框内、横跨单个叙事时长，虚线边框 + 标题。

点框标题选中框、双击改名、Delete 删除（级联其下所有内容）；点框内分镜/旁白/字幕块正常编辑（框不挡）。

**Shot 拖拽动画细节**：
- **被拖卡片**：拖起后缩小变虚影（opacity 0.3 + scale 0.9），标识该位置已被移出
- **FLIP 重排**：拖动时所有卡片（含虚影）实时移动到"假设松手后"的目标位置 —— 如把 ABCDE 中的 B 拖向末尾，CDE 立即左移填满 B 的空位、B 虚影移到末尾，整个过程丝滑动画
- **no-op 不显示空隙**：在同一叙事内拖动但未跨越其他分镜时（插入位置等于原位置），不出现空隙和虚线框，因为没有实际移动
- **无缝释放**：松手时因拖拽过程中卡片已就位，释放瞬间无多余回弹动画，虚影平滑变回实体
- **跨叙事/外部拖入**：显示带缩略图的虚线占位框（dashed border），兄弟卡片让出空隙
- **拖拽时隐藏 hover 详情**：拖动期间不显示分镜悬停详情弹窗，避免遮挡目标位置

### 素材面板

**以完整视频（media）为单位展示**，双列网格布局：

- **工具栏**（一行紧凑排列，高度 26px）：搜索框 + 类型筛选（全部/视频/图片）+ 排序下拉（名称/时长/拍摄时间）

## 通用组件

| 组件 | 实现方式 |
|------|---------|
| 通知 | `Quasar.Notify`，顶部弹出，1800ms 自动消失 |
| 对话框 | `q-dialog` + `q-card`，16px 圆角，毛玻璃背景。下拉菜单覆盖方角样式 `.q-menu--square { border-radius: 8px }` |
| 上下文菜单 | 自定义 HTML 定位，含 `q-list` + 快捷键提示 |
| 颜色选择 | 行内圆点，点击切换（非独立组件） |
| 进度条 | 自定义 div（`var(--accent)` 色）+ "done/total" 标签 + 24px Lottie 动画 + 弹出任务列表 |
| 动画 | Lottie（AI 分析等待） |
| 无限滚动 | IntersectionObserver，200px 预加载距离。小缩放时 `_checkFill()` 自动检测内容是否填满容器，不足时自动加载更多 |
