# 标签维护重设计

状态：开发源码与隔离浏览器验证完成，尚未打包或替换本轮生产应用。当前已安装版本仍为此前发布的 1.0.16。

用户确认标签树直接展开在维护页左侧，可逐级收起和打开；右侧维护所选标签。当前规则纳入 [UI 规范 §11.1](UI-SPEC.md)，覆盖此前维护入口依赖顶部下拉的布局约定。智能分类的主导航树和素材浏览结构保持原有职责。

## 布局与交互

- 主区域采用 240px 内容树和弹性编辑区，窄窗口树宽 216px，区域间隙 8px。主导航仍只有一列，维护树不在导航中重复渲染。
- 树初次展开顶层分支，打开深层标签时展开祖先并滚到当前行。箭头独立获得焦点，只改变展开状态，不切换标签或重置输入。
- 两栏顶部工具行 32px；维护功能使用 28px 组内按钮、滑动选中底片和主题语义色，支持方向键与 Home/End。名称、路径、保存和图集动作放在右侧内容头部。
- 表单按基本信息、同义表达、合并拆分、直接标注素材、例图分段。保留新增、父级、停用预览、正反例、拆分目标、AI 建议、人工确认、任务控制和撤销，不通过删除入口简化页面。
- 两个内容区域各自一处滚动，外层页面不滚动；加载、空树、无选择和失败分别表达。读取失败保留已加载标签和未保存输入，重试不会先清空内容。

## 实际验证

- `tests/taxonomy-maintenance-browser.cjs`：9 组通过，覆盖常驻树替代选择菜单、深层展开、独立箭头、保存、全部维护页签、键盘、默认展开、加载/空态/失败重试、四主题明暗与 1000/1280/1600px。24 个外观/窗口组合均无整页横向溢出，几何保持稳定，字段边框跟随主题。
- 原标签维护流程 4 组、分类布局 10 组通过；新增/子标签、定义与同义表达、素材图集和详情返回、已有分析的待审与确认、完成任务、窄窗口、选区传递及图集导航保持可用。
- 标签状态 30、前端行为 16、图库状态 17 及分级选择器专项通过；JavaScript 语法和 diff 空白检查通过。
- 所有写操作只使用合成临时资料库，没有操作正式资料库、源素材、外部模型或真实 AI。另使用完整的 1,107 个预置标签建立只读预览。

测试产物位于已忽略的 `build/taxonomy-maintenance-validation/`，预览为本机临时服务。截图及一次性 JSON 不放入 docs。真实长期识别负载和完整 WCAG 审计不属于本轮布局验证范围。
