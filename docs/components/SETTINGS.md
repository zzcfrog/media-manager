# 设置分组组件

更新于2026-11-07，UI规范1.43。七个设置页统一使用B「浅底成组」，组件只负责呈现；草稿、下载、模型核验与保存仍由原有Root mixin管理。

## 结构与接口

`SettingsGroup`包含标题行（图标、h3、右侧短说明）和一个浅底内容区。`SettingsRow`包含左侧名称/帮助和右侧控件区。主题预览与人脸三卡等复杂内容可直接放入分组。

| 组件 | 参数及插槽 |
| --- | --- |
| settings-group | 必填title；可选icon、note、label；surface默认grouped，none表示保留标题但不叠加底色；默认内容及heading插槽 |
| settings-row | 必填label；help为按需展开的说明；note为控件旁短说明；默认控件及help插槽 |
| settings-help | 必填title、text；独立管理展开状态，不写业务设置 |
| settings-model-status | 展示既有Root的本地模型下载进度/错误，供图片、视频、音乐及共用补充模型复用 |

```html
<settings-group title="图片输入" icon="image">
  <settings-row label="压缩尺寸" help="只用于分析副本。">
    <q-select v-model="draft.size" aria-label="压缩尺寸" dense filled></q-select>
  </settings-row>
</settings-group>
```

分组标题14px/600，选项13px，短说明11px；次级表面14px圆角、组间18px、选项行至少44px。控件区宽320px且不超过52%，字段高34px，数字字段可收窄至88px。小于600px时字段可换到下一行；主题只改变颜色与材质。人脸卡片保持三阶段横排及既有模型名称、文件、复核开关和核验状态，不由通用行组件替代。

视频人脸分组依次放置「视频压缩／检测帧率／每次出镜取样数」。视频压缩沿用通用行及选择器，选项仅1080p与原片、默认1080p，不另加常驻说明；名称旁信息按钮按需解释实时处理及已完成结果保留。保存、取消、失败重试和旧后台版本检查沿用既有设置机制，分组不管理扫描任务。

## 状态、交互与可访问性

每个输入/选择器仍提供自己的准确aria-label，开关保留role=switch和原值类型。分组默认使用与字段不同的可访问名称，避免同名查找混淆；可通过label保留既有分组语义。帮助按钮支持Tab、Enter/Space、Escape、关闭按钮及返回焦点；桌面信息按钮沿用20px视觉尺寸，不作为触摸尺寸合规声明。密码显示按钮支持键盘与动态名称。

加载期间沿用原inert/禁用规则；下载与核验不会因移动控件位置而保存模型设置。进度、取消、缺模型、错误、无桌面桥接/环境锁定仍就地可见。迁移仅在主动勾选时展开复制校验与保留源文件的必要说明；不把关键后果仅藏进帮助。

设置外框高度固定为`min(740px, 100vh - 48px)`，切换页签、加载或显示错误时均不改变；内容区填满剩余高度，只有`.q-panel.scroll`滚动。短页留白，底部操作固定，长页最后一项可完整到达。保留原来确认、取消、部分保存失败后只重试剩余项，以及迟到响应隔离。通用主题和外观继续即时预览/保存；工具栏外观浮层不套用设置分组。
