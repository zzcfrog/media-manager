# 人物归组控件

位置：设置 → 人脸识别 → 套装模型之后、视频设置之前。沿用 `SettingsGroup` / `SettingsRow` 和主题令牌，不改变设置弹窗的固定高度。

分组标题及当前有效阈值在一行；第一行为阈值名称、问号和数字输入，第二行为自动校准名称、反馈计数和开关。右侧备注与数字控件对齐，不增加独立长说明。

| 字段 | 类型及默认值 | 规则 |
| --- | --- | --- |
| `similarity_threshold` | number，0.55 | 0.45～0.85，步长0.01；数值降低会增加错合并风险 |
| `adaptive_threshold` | boolean，true | 根据当前模型的人工反馈，在手动值±0.05内校准 |
| `/api/people/status.grouping` | 只读对象 | 基准／有效阈值、启用态、同一人／不同人反馈计数、是否已达到校准门槛 |

点确定才保存。取消丢弃草稿；网络/校验失败保留编辑内容。只影响后续识别，不重扫或重新归并已有相册，不更换模型，也不重置排队任务。手动关闭校准后严格使用手动阈值。

问号由点击、Enter或Space打开，可点击关闭或Escape，关闭后焦点返回问号。数值输入与开关均有中英文可访问名称；错误使用现有设置错误区域。加载/读取失败沿用整个识别面板的状态，不呈现未加载的默认草稿。

校准读取最近100次有效人工人物操作的现有撤销历史，无新增数据库字段或训练框架。合并、移入已有人物、确认归属产生同一人依据；拆分、从错误人物移出和「不同的人」产生不同人依据；忽略、命名、隐藏不构成依据。仅比较同模型且质量合格的人脸特征，每次操作每模型每类至多一条统计，撤销的操作不参与。

同一人反馈至少5次时，参考相似度20%分位数减0.02，允许在手动值以下适度放宽；不同人反馈至少3次时，以90%分位数加0.02作为收紧依据。不同人依据优先，最终限制在手动阈值±0.05及全局0.45～0.85内。它是有界统计校准，不是识别准确率承诺，不训练或上传模型。原待核对0.40、候选领先0.08及人工排除保护保留。

验证：`tests/test_people_grouping.py`、`tests/people-grouping-settings-browser.cjs`。覆盖边界/非法值原子拒绝、保存/取消/失败、模型隔离、样本门槛、关闭、撤销、队列不变、键盘/可访问名称、四主题亮暗和紧凑窗口。后续视觉可参照 `build/raw-and-grouping-2026-11-07/browser/`。
