# 人脸核对与纠正

2026-11-07，用户以补发的双列卡片参考图明确最终布局。已随1.0.21更新本机，见[安装与资料核验记录](../local-update-1.0.21-2026-11-07.json)。尺寸、主题与文字遵循[UI规范](../UI-SPEC.md)。

## 页面与操作

「待确认人脸」在常规桌面采用固定双列卡片，窗口宽不超过1100px时单列。左侧大图展示待确认人脸，右侧并排展示当前归属和建议归属，头像上方是角色、下方是名称；操作放在底部。归属包含名称和人物封面，同名者用已有编号区分；未归组及无建议分别显示明确文字。低质量仅说明画质不足，不声称已经识别错误。人物头像进入人物图集，待确认的脸打开原素材；返回恢复核对类别和页码。

「原归属正确」沿用人工确认操作；无归属时改为「暂时忽略」。点击「纠正／指定人物」在按钮旁打开一个头像面板，不撑高卡片或改变网格。面板宽480px并自动避让窗口边缘，头像三列且限高滚动；搜索、选择与提交都在同一面板内。建议人物在头像列表前列，用户仍须明确点选并确认。新建人物、暂不归组、非人脸及确认当前归属都是待提交选项，选择本身不写入。

「可能是同一人」保留原合并预览、不同人、忽略、分页及撤销流程，不以单张人脸纠正代替人物合并。

2026-11-07，1.0.22新增「全量重新扫描」，已更新本机：入口位于待核对工具栏右侧，两个核对分类共用。弹窗显示全部待核对项所关联照片／视频的去重数量，包含所有分页；不是整个素材库。人脸项取其原素材，合并建议取两侧人物的现有素材成员；已解决和忽略项不纳入。即使旧脸已失活，只要核对项仍待处理，其素材仍会纳入，避免界面可见项被遗漏。

弹窗沿用32px按钮、主题色、圆角及原扫描模型设置行；只显示数量、保留人工处理与离线等待说明，不提供范围和跳过选择。读取有loading、空、失败重试；空或未读到范围时不能开始，取消／Escape不排队。开始后关闭弹窗，Header管理暂停、继续、重试和停止；正在排队或识别的素材不重复添加。旧结果、命名、合并、排除与人工纠正在成功重扫前保留，重扫仍用既有观察匹配及人工保护规则；不通过清空人物或待核对记录实现。

`GET /api/people/reviews/rescan`只读返回`{total,active}`；`POST /api/people/jobs`接受`{scope:'review',existing:'rescan'}`，服务端重新查询全部待核对关联素材，不接收当前分页ID，不受1000项手动选区上限限制，返回既有`{total,queued,skipped}`。预览与确认之间状态可能变化，以实际排队结果为准。普通照片无原片且缓存长边不足800px、RAW无原片且无至少1600px高清缓存时等待，不再使用320px网格图生成人脸。连接硬盘后在Header重试，或再次全量重扫。

## 组件契约

`PeopleFaceEditor`位于`frontend/js/people.js`，由`PeoplePage`和`PeopleDialogs`局部注册。待核对页由Quasar QMenu承载锚定面板，语义为非模态dialog，沿用位置避让、焦点与外部关闭；检查器、详情及批量纠正保留弹窗容器，内部复用同一编辑器。

QResizeObserver在头像载入、切换操作或错误改变内容高度时重新定位面板，避免初始加载占位较矮、实际内容展开后超出窗口。面板关闭以受控展开状态同步，不依赖关闭动画结束事件；隐藏节点仍处于退场动画时，不把它误判为仍打开的编辑器。

| 输入／事件 | 约定 |
| --- | --- |
| `faces: Array` | 本次纠正的人脸，包含ID、版本、归属和裁切URL；创建编辑器时复制ID与版本，之后的后台刷新不覆盖快照 |
| `suggested: Object/null` | 可选建议人物，列表前置并标注；不自动选中或保存 |
| `showFaces: Boolean` | 默认显示待纠正脸及当前归属；卡片已有这些信息，面板传false避免重复 |
| `busy(Boolean)` | 请求期间同步禁用父容器关闭、重复操作及类别切换；成功事件前解除busy |
| `cancel` | 取消或Escape，不写库；关闭后回到触发按钮，未提交时也可点击面板外关闭 |
| `saved(result)` | 请求已成功并刷新共享人物资料；沿用已有撤销提示 |

目标列表读取可见与隐藏人物；隐藏状态和同名编号清楚标记，允许选择已有隐藏人物，保持原能力。列表读取有加载、空、搜索无结果、错误和重试状态。读取失败不能确认未知目标，新建或明确移出不依赖列表。头像按主题显示选中底色、轮廓及对勾；原生button保留可访问名称、aria-pressed、Tab、Enter／Space与焦点轮廓。

## 写入与异步边界

1.0.23视频归组修复已更新本机，新增两类自动原因：「出镜待核对」表示轨迹特征或既有归属有冲突，「归属待核对」表示候选匹配尚不明确；不将它们统称为画质不足。卡片沿用当前／建议归属及头像纠正，原因通过aria-describedby关联原图按钮，支持辅助技术读取。既有已忽略建议不重开，成功重扫不再发现的自动观察会解决其提示。原始人脸特征与人工决定保留，历史人物不会被自动批量合并。算法边界见[视频扫描](../PEOPLE-SCANNING.md)，安装和续跑见[更新记录](../local-update-1.0.23-2026-11-07.json)。

纠正操作复用`POST /api/people/faces/decide`的move／new／unassigned／not_face／confirm，提交展开时的ID与版本；不创建扫描或分类任务。全量重新扫描复用people_jobs持久队列，没有新增表、字段、识别模型或阈值。保存前的头像点选、搜索、切换操作和取消均不写入。

提交中禁用重复动作并阻止面板外点击或Escape关闭，失败保留草稿与错误；遇到版本冲突由用户重新核对，不自动接受新版本。成功刷新列表、Footer与全局人物资料并沿用撤销；离开页面或打开另一弹窗后，旧异步完成不关闭新界面。一个旧面板的关闭事件不关闭另一个新打开的面板。刷新不改变仍有效的编辑对象；已解决的卡片移出后释放编辑器。

## 验证入口

`PEOPLE_REVIEW_FIXTURE=1`启用`tests/people-browser-fixture.py`中的独立合成核对样本。`tests/people-review-inline-browser.cjs`沿用原脚本名，通过`PEOPLE_BROWSER_FIXTURE`连接，现验证双列卡片／窄窗单列、浮层在视口内、外部点击关闭、真实纠正／撤销接口、原图返回、批量功能、加载与失败、四主题明暗及紧凑中英文。原`people-browser.cjs`和`people-layout-browser.cjs`使用不带该标记的独立夹具回归，不混用会改变成员数的测试库。

重扫浏览器另启用`PEOPLE_RESCAN_FIXTURE=1`，其测试库保持TESTING且推理worker关闭，仅允许review重扫与任务控制写入。运行`tests/people-review-rescan-browser.cjs`检查真实排队接口、跨页范围、取消／错误重试／迟到结果、四主题明暗、1000／1440px、键盘与Chromium可访问树、Header控制和现有核对记录保留。`tests/test_people_review_rescan.py`覆盖超过1000项、去重、活动租约保留、停用、人工处理与低清离线保护。
